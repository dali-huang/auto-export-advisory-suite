# 中国汽车出口国家经理 · 专家顾问团 Skill 套件

> 面向乘用车出海国家经理：一个三视角专家团（原 3 位专家已合并）、三本著作方法论、六个岗位数据方法和一个中资品牌诊断方法，由总控 Skill 路由与评审；六个岗位方法均含中资品牌对比。

## 套件结构

12 个 Skill（1 三视角专家团 + 3 著作方法论 + 6 岗位数据方法 + 1 中资诊断 + 1 总控），可独立安装、也可成套使用。

## 市场分析的 6 个板块（按 4P 岗位）

| 板块 | 岗位 / 4P | 内容 | 主要产出 |
|---|---|---|---|
| 0 市场与宏观 | 市场情报 / 总览 | 宏观需求、市场规模、细分结构、单国画像 | 规模、结构、增长来源、国别压力 |
| 1 产品 | Product | 型谱、配置、本地化适配、产品经济性、生命周期 | 型谱地图、配置建议、产品诊断卡 |
| 2 销售与价格 | Price | 海关贸易、竞品份额、真实 TP/MSRP | 进口、份额、价格带、增长拆解 |
| 3 网络发展 | Place | 经销商网络、招商、覆盖与绩效 | 门店数、城市覆盖、单店效率、缺口 |
| 4 营销动作 | Promotion | campaign、激励、媒体与声量 | 动作日历、激励强度、SOV |
| 5 售后 | 售后 / 客户运营 | 服务网络、备件、保修、CSI、召回 | 售后能力与上市门槛 |

六板块的岗位画像均来自公开招聘 JD 的共性归纳，原始来源汇总在 [jd-sources.md](references/jd-sources.md)（36 条，检索日 2026-10-30）；样本结构说明见文件末尾（中资/外资/经销商侧分布与缺口）。

每个板块都含一节"中资品牌专项"：市场看中资份额与结构、产品看中资型谱与配置价值比、销售与价格看中资份额/价格实现率/原产进口、网络看中资网点与单店效率、营销看中资 SOV 与激励强度、售后看中资备件等待与保修履约。中资的统一口径（中资资本 / 中国品牌 / 中国原产）由各板块声明，结构性诊断统一交给 `auto-export-method-china-brand`（放在最后使用）。

## 安装方式

每个子目录是一个独立、可单独安装的 Skill，可复制到 Agent 的 Skills 目录（Claude Code / Codex / Trae 等），互不依赖。

- 单独安装：将目标子目录（如 `auto-export-advisor-trio/`）复制到对应 Agent 的 Skills 目录。

- 成套使用：建议**先安装总控 Skill**，再安装三视角专家团与三本方法论 Skill（宏观分析层），最后按需安装六个岗位数据方法与中资诊断（数据层）；总控负责路由，未安装的子 Skill 会在路由时提示缺失。

- 资料文件：每个 Skill 的 `references/` 包含研究底稿或框架源文件，供追溯依据；`references/contemporary-export-methods.md` 是当代出口方法的统一研究底稿。

## 快速上手

### 场景一：单视角问答

**提示词**：「用李书福的视角看，在泰国找总代，总部和国家团队的权责边界该怎么划？」
**预期产出**：`auto-export-advisor-trio` 切到李书福单镜，给出伙伴互补、权责边界、根基能力三方面判断，标注事实与推断，并提示当地代理法/数据法规需另行核验。

### 场景二：开评审会（多视角）

**提示词**：「开评审：印尼市场要从 CBU 转 CKD，各顾问怎么看？」
**预期产出**：总控按宏观分析层调度：三视角专家团三镜并行（李书福＝伙伴与长期投入、Ghemawat＝CAGE 距离与进入模式、Grove＝产出与拐点）＋渠道/定价/运营方法论分别给意见，最终汇总共识、分歧、关键假设与验证指标。

### 场景三：套用模板出汇报

**提示词**：「用定价方法论，给 X 车型在墨西哥的上市定价出一份决策卡。」
**预期产出**：基于「单次价格决策卡 + 贡献及折扣瀑布」框架，输出成交价口径、竞品替代、经济桥、盈亏平衡销量与情景敏感性，标注税费/汇率为「未核验」。

### 场景四：单国市场画像

**提示词**：「做一份 2026 年墨西哥乘用车市场画像，要有份额、TP/MSRP、经销商门店数量、主要营销动作和售后能力。」
**预期产出**：按 4P 岗位分块固定口径，输出规模结构、集团/品牌份额与增长拆解、中资品牌位置、价格阶梯与 TP 证据、按类型分列的在营网点与城市覆盖、campaign 日历与激励强度、服务网络与备件/保修/CSI 缺口；每张表带来源、观察期、覆盖限制和缺口，不编造缺失数据。

### 场景五：产品型谱与配置

**提示词**：「看墨西哥 2026 年在售车型，把 20–35 万比索价格带的型谱画出来，找空白、重叠和配置差距。」
**预期产出**：细分×价格带型谱地图、直接替代竞品配置矩阵、装备价值比、中资产品组合对标（覆盖差/价格带占位/内部重叠/配置价值比）、本地化适配清单（法规/油品/气候/路况/充电/语言/ADAS）、产品经济性与生命周期建议；缺成本或选装率标 NA。

### 场景六：中资品牌国别诊断

**提示词**：「诊断比亚迪在墨西哥现在到底卡在哪：份额、价格、渠道、品牌还是售后？」
**预期产出**：先定中资资本/中国品牌/中国原产口径，再按五维与中资八问逐项给事实、判断、证据等级和缺口，输出增长质量拆解、拐点信号与条件化动作建议。

## 诚实边界

本套件可整理官方及授权数据；以下事项仍需当次取证或专业核验，未取得证据标注「未核验/不可得」：

- 具体国家的准入法规、关税与非关税壁垒、认证要求

- 信用证条款、外汇管制、贸易救济与电子单证法律效力

- 当地用工合规、数据法规、代理法、召回制度

- 未获授权的内部销量、库存、成交合同、授信条件等数据

AI 可辅助整理与生成情景；公式与数据须可复算，外部执行需明确授权。

## 六个数据方法怎么用

- 「用市场方法分析某国乘用车市场规模、细分结构和宏观需求，区分实际值/估算/预测。」

- 「用产品方法画某国某价格带的型谱地图，找空白、重叠和配置差距，列本地化适配清单。」

- 「用海关贸易方法分析某国近24个月乘用车进口，核实HS版本，分别给数量和金额份额。」

- 「用竞品方法比较某国同一细分的在售车型，列份额分母、报送覆盖及价格证据。」

- 「核查某车型当地MSRP和真实TP；取不到成交证据就标未取得，保留报价条件。」

- 「统计某国某品牌的经销商门店数量：按类型分列，标在营状态、城市覆盖和单店效率，并和竞品同口径比较。」

- 「梳理某国近12个月主要品牌的营销动作：建campaign日历、激励强度和证据等级，区分厂商动作与经销商自促。」

- 「评估某品牌在某国的售后能力：服务网络、备件等待、保修条款与履约、CSI/投诉、召回响应，缺授权数据标 NA。」

- 「单独给中资品牌算份额：先定中资资本/中国品牌/中国原产口径，再给中资集团合计份额、中资内部 CR3、品牌数与增速贡献、TP 分位和原产进口结构。」

- 「把中资网点单列出来：网点数、城市覆盖、单店效率、多品牌共用率和建店节奏，和日系/欧系/本土品牌同口径比。」

- 「给中资售后单独做一列：服务半径、常用件/冷门件等待、保修履约与拒赔、CSI、召回响应和残值。」

- 「给中资做产品组合诊断：中资型谱在哪些细分价格带有覆盖、在哪些空白，配置价值比和内部重叠如何。」

海关是贸易事实的优先来源，**海关均价不是TP，进口份额不是零售份额**。门店数不是销售能力，地图 POI 不是授权在营；营销声量不是品牌力；保修文本不是履约能力；配置多不等于产品力强。新增方法不预填不存在的真实数据；每次保存原始文件、筛选条件、单位、观察期与来源定位。已加入 [INEGI 官方历史销量复算样例](auto-export-method-sales-price/references/framework.md)，用于验证同比和统计覆盖，不代表用户指定市场的最新报告。尚未指定目标国家/车型/期间时，先使用方法与取数规范，不编造具体市场结论。

## 中资品牌诊断怎么用

- 「先判断：这里的'中资'是中资资本、中国品牌还是中国原产？三种口径分开算。」

- 「诊断某中国品牌在某国为什么卡住：份额、价格带、渠道、品牌、售后逐维给证据。」

- 「拆增长质量：多少来自大盘、多少来自细分红利、多少来自份额夺取、多少是一次性铺货。」

- 「中资八问：品牌信任、残值、售后备件、渠道盈利、原产地合规、平行出口、集团内竞争、总部权责。」

诊断方法只组织证据和判断，不编造残值、经销商利润或内部库存；这些需授权内部数据，缺失标 NA。关税、认证、补贴与原产地规则须取得官方现行文件，否则标「未核验」。

## 构建工作流

有兴趣了解套件如何生成，可按以下阶段追溯：

1. **候选名单**（`CANDIDATES.md`）：初选 3 专家 + 3 方法论 + 1 总控，核验语料来源数量与独立性。
2. **调研**：逐条采集一手/署名来源，记录证据与矛盾，达不到门槛则替换。
3. **蒸馏**：每位专家提炼 3 个心智模型 + 7 条决策启发式；每本方法论提炼框架与可执行规则，标注章节来源。
4. **构建**：写入各子目录 `SKILL.md` 与 `references/`；当代出口应用作为独立改编模块，不冒充原书或专家观点。
5. **QA**（`RESEARCH-REVIEW.md`）：审阅范围、核心输出与限制，预置多模型分歧与决策条件。
