# 岗位 JD 来源汇总（六板块）

检索日：2026-10-30。以下为公开招聘页面，用于归纳岗位职责、技能与产出，**不是单一企业的标准流程**，也不代表行业统一做法。招聘页可能下线，链接失效时以本文件摘录为准。

## 使用规则

1. JD 只作"岗位职责线索"，不能当企业制度、考核标准或行业基准。
2. 同一板块尽量同时取中资与外资样本，避免只用一类企业推断全行业。
3. 职责归纳与技能要求写入各板块 SKILL.md；本文件只保留来源与摘录，便于追溯。
4. 引用时必须标注检索日；超过 12 个月的 JD 视为过期线索。

## 样本结构说明

- 中资样本集中在市场、产品、销售价格、网络、营销五个板块；售后板块的中资样本偏经销商侧，缺主机厂海外售后岗，故售后 SKILL 的职责归纳含较多外资/经销商成分。
- 外资样本多为欧美日韩主机厂与经销商集团，职责描述更细，但考核口径与中资不同；对比时不要直接套用其指标定义。
- 经销商侧样本（4S 市场经理、服务经理）只反映门店执行层，不能当作主机厂岗位标准。
