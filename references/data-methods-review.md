## 行为检查

| 输入情形 | 模块应输出的行为 |
|---|---|
| 只有海关金额和kg重量 | 不生成美元/辆，不生成TP |
| 只有中国原产进口数量 | 仅分析来源结构，不输出中国品牌零售份额 |
| 某品牌退出报送 | 披露覆盖变化，不把缺报填零或当销量崩塌 |
| 只有官网起售价和经销商促销广告 | 标MSRP/Quote，TP保持未取得 |
| 机构ATP脚注不含消费者激励 | 保留该口径，不能冒充激励后净支付 |
| WEO历史项为工作人员估算 | 标机构估算，不因年份已过而标实际值 |

上表为规则走查，不是独立模型实测。后续指定目标国、车型和期间后，按各模块取数契约开展实数分析；当前交付的是可复用方法及可核验历史样例。
