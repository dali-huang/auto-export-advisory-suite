# 宏观需求与国别压力分析

本方法是 [乘用车实务改编]。数据源及字段见 [macro.md](macro.md)，仅在本场景加载。

## 分析路径

1. 先以当地零售/注册、海关和保有量建立基线，再找可能解释变化的收入、就业、贷款利率、汇率、通胀和能源成本；GDP 增长不能直接换算汽车需求增长。
2. 对齐期间、币种、名义/实际、季调/未季调、存量/流量、观测/估算/预测。年度收入不能假装当月收入，政策利率不能假装汽车贷款 APR。
3. 需求拆为保有量净增与更新，另考虑二手车进口、报废/出口等流量；资料不足时不能仅凭“保有量低”报潜在销量。
4. 从需求、可负担性、进口依赖、金融/外汇、能源及渠道承载力并列比较国家。没有用户权重时不给伪精确总分；可给不同权重情景，但标明判断性权重。
5. 做基准、货币贬值、融资收紧、供货受限等情景，每个冲击量明列为假设。输出对现金、价格和发运的影响，不把情景当机构预测。

## 可用测算

| 测算 | 口径和限制 |
|---|---|
| 价格/收入 | 当地含必要费用购车价÷对应目标家庭年度可支配收入；GDP人均不可替代目标家庭收入 |
| 月供负担 | 月供÷对应家庭月可支配收入；另列首付和尾款，无统一“安全线” |
| 表观供给 | 同范围本地产量+进口−出口；不是实际零售或需求，须说明库存变化及统计边界 |
| 进口成本汇率压力 | 外币成本×当地货币/外币汇率；贬值定义和报价方向写清，不默认100%转嫁消费者 |
| 燃油/电动 TCO | 里程、能耗、当地适用能源价格、保险、保养、融资和残值；缺项做情景，不能捏造真实残值 |

结论必须回答：变化是总需求、产品结构、金融约束还是供给约束的证据？若无法识别，列并存解释与验证指标。回归/相关性不直接声称因果；小样本不估精确销量弹性。

输出 `指标｜定义/单位｜观察期｜发布时间/版本｜观测/估算/预测｜来源｜覆盖/滞后`，附国别比较、情景及需要当地团队验证的事项。税率、补贴和准入须查官方现行文件及生效日；官方取不到就标未核验，不据此批准投资。
