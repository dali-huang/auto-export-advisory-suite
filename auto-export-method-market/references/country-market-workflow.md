# 单国乘用车市场精细化分析

本方法为 [乘用车实务改编]。分块取证规则分别由 `auto-export-method-sales-price`（份额/海关/价格）、`auto-export-method-network`（门店）、`auto-export-method-marketing`（营销）、`auto-export-method-aftersales`（售后）承载，宏观见同目录 [macro-workflow.md](macro-workflow.md)。本文件只规定顺序、口径和交付物；对应板块 Skill 未安装时，跳过该块并在缺口表标注"未安装/未取证"。

## 适用与不适用

适用：给定国家、期间和目的（进入评估、年度计划、竞品监测、上市准备），产出一份可复算的市场画像。

不适用：全球市场排名、跨口径国家对比、替代企业内部的成交/库存/线索数据。政策、税率、认证须查官方现行文件，否则标"未核验"。

## 0. 先写口径，再算数

开工前固定并写入输出首页：

| 项 | 必填内容 |
|---|---|
| 国家/地区 | 全国或指定区域；区域分析不外推全国 |
| 期间 | 单月、YTD、R12M、同比；跨期比较用同期 |
| 车辆范围 | 新车/二手车；轿车/SUV/MPV/皮卡按目的国定义；燃油/混动/纯电 |
| 统计阶段 | 零售、注册、批发、海关进口分表；不混算 |
| 品牌层次 | 集团/品牌/车型；别名与集团归属按生效日期 |
| 币种/汇率 | 当地币与报告币，汇率日期与来源 |
| 数据边界 | 观察期、检索日、报送覆盖、缺报品牌、修订状态 |

"门店数量""市场份额""平均价格"在未写口径前都不可比。

## 1. 建可比市场

- 分母与分子同口径；总量不足时先解决覆盖，不先算份额。
- 细分按车身＋动力；有可靠 TP 时再叠加价格带。细分定义跨期保持一致。
- 竞品池分三层：直接替代（用途/客群、车身、可成交价格接近）、跨级替代、潜在进入者。
- 海关进口、注册/零售、批发分别建表；中国原产 ≠ 中国品牌，进口量 ≠ 终端销量。

## 2. 规模与结构

总量、同比、R12M、YTD；动力结构、车身结构、价格带结构；品牌集中度 CR3/HHI。
实际值、机构估算、预测分列；不得把部分月份年化，不得把累计同比当单月同比。

## 3. 份额与增长质量

集团、品牌、车型三层份额；本期份额−基期份额，以百分点表示。

单层拆解：`Δq = s₀×(M₁−M₀) + M₁×(s₁−s₀)`（市场效应＋份额效应）。

细分层拆解（品牌 b、细分 i）：

```
Δq_b = Σᵢ (Mᵢ₁−Mᵢ₀)·s_bi₀        ← 细分市场增长
     + Σᵢ Mᵢ₀·(s_bi₁−s_bi₀)       ← 细分内份额变化
     + Σᵢ (Mᵢ₁−Mᵢ₀)·(s_bi₁−s_bi₀) ← 交互项
```

回答"增长来自大盘、细分红利、份额夺取，还是一次性车队/铺货/降价清库"。检查样本增减、缺供、新车上市、政策与促销；相关不等于因果。

## 4. TP / MSRP 与价格带

- 先取官方 MSRP 表，再按 `auto-export-method-sales-price` 的价格工作流分层取 TP：实证、ATP 统计、Quote、Scenario。
- 同口径折扣率 `1−TP/MSRP`、价格实现率 `TP/MSRP`；无 TP 标"未取得"，保留 MSRP/Quote 列。
- 做价格阶梯：同一细分按可比 TP 从低到高排序，标出车型空档、相邻替代和价格重叠；不能用入门 MSRP 对比竞品高配 TP。
- 价格带宽度与国家税制、收入、金融渗透相关；跨市场比较前先换算到同币种、同税费口径。

## 5. 经销商网络

按 `auto-export-method-network` 的网络工作流统计在营网点类型、城市覆盖、网络密度、单店效率与覆盖缺口，与 3–5 个直接竞品同口径对比。
门店数不是销售能力；新增网点前核对建店成本、授权法规和售后资质，渠道设计交给渠道方法论。

## 6. 营销动作

按 `auto-export-method-marketing` 的营销工作流建 campaign 日历、动作类型、激励强度、媒体与 SOV。
营销动作是策略信号；与价格、库存、渠道扩张、政策并列观察，不单独归因销量。

## 7. 售后

按 `auto-export-method-aftersales` 的售后工作流统计服务网络、备件满足率与等待、保修条款与履约、一次修复率、CSI/投诉、召回响应。
售后与销售网络分开评估；保修文本不等于履约能力，售后数据缺失标 NA，不用行业均值填充。

## 8. 综合判断

机会矩阵：`细分/价格带 × 规模 × 增长 × 竞争强度 × 价格空间 × 网络可行性 × 售后可行性 × 政策合规`。

- 结论条件化：在什么条件下进入、加码、观望或退出；写清触发条件。
- 每条结论标注证据等级（实证/估算/预测/框架推断）和数据缺口。
- 需要排序时说明权重是判断性的，不输出伪精确总分。
- 数据不足时只交付可验证部分，不给全市场排名或精确份额。

## 输出模板

```
# [国家] 乘用车市场画像（[期间]，[统计阶段]）
## 0. 口径与数据边界
## 1. 市场总览
   总量｜同比｜R12M｜动力结构｜车身结构
## 2. 细分结构与价格带
   细分表｜价格阶梯｜空档与重叠
## 3. 份额与集中度
   集团/品牌表：本期量｜同期量｜分母｜份额｜变动pp｜来源
   CR3/HHI｜增长拆解
## 3.5 中资品牌位置
   三口径（中资资本/中国品牌/中国原产）分列｜中资份额｜中资内部 CR3｜品牌数与增速贡献｜价格带分布｜原产进口结构｜政策暴露
   对比列：中资、日系、韩系、欧系、美系、本土品牌
## 4. TP / MSRP
   MSRP 表｜TP 证据表｜折扣率/实现率｜未取得项
## 5. 经销商网络
   网点类型小计｜城市覆盖｜密度｜单店效率｜竞品对比｜覆盖缺口
## 6. 营销动作
   campaign 日历｜激励强度｜媒体/SOV｜证据等级
## 7. 售后
   服务网络｜备件｜保修｜一次修复/CSI｜召回｜证据等级
## 8. 判断
   机会矩阵｜条件化结论｜风险｜验证指标
## 9. 数据缺口与下一步取证
   缺什么｜为什么缺｜替代源｜影响哪条结论
## 附录
   来源定位｜观察期｜公式｜原始文件名｜检索日
```

## 数据缺口处理

| 缺口 | 处理 |
|---|---|
| 无 TP | 输出 MSRP/Quote 阶梯，TP 标"未取得"，不按固定折扣估算 |
| 无门店数据 | 官方 locator + 地图抽样 + 协会名录，标覆盖与去重方法 |
| 无营销监测 | 只列公开素材与动作，SOV/花费标 NA |
| 无售后数据 | 只列公开保修条款、服务 locator 与召回，备件/CSI 标 NA |
| 无品牌字段 | 只做贸易与结构分析，不推品牌份额 |
| 缺报品牌 | 披露覆盖变化，不把缺填报零、不当份额崩塌 |
| 政策/税率/认证未取得 | 标"未核验"，指向官方入口，不据此下投资结论 |

## 检查清单

- [ ] 国家、期间、车辆范围、统计阶段、币种、检索日已写入
- [ ] 分子分母同口径，缺报与覆盖已披露
- [ ] 海关、注册、批发未混算；中国原产未当中国品牌
- [ ] 中资品牌单独列示（份额/内部集中度/品牌数/价格带/来源结构），口径已标注
- [ ] 价格用 TP 或明确标"未取得"，未用海关均价/广告价冒充
- [ ] 门店口径统一、去重、含在营状态，竞品同口径
- [ ] 营销动作区分厂商与经销商，证据等级已标
- [ ] 售后与销售网络分开，保修文本未当履约能力
- [ ] 结论条件化，权重判断性，缺口指向下一步取证
