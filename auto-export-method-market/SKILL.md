# 市场与宏观分析（含单国画像）

本方法为 [乘用车实务改编]，对应"市场情报 / 国家市场分析"岗位。它回答"这个国家市场多大、长什么样、增长从哪来、宏观压力如何"，不替代销售、网络、营销、售后各板块的取证。

## 一、岗位画像（JD 归纳）

| 项 | 内容 |
|---|---|
| 典型职责 | 一手/二手市场调研；消费者偏好与购买行为；细分市场与用车场景；竞品与行业趋势；政策法规与技术标准跟踪；销量预测与情景分析；市场情报报告与 BI 看板 |
| 常见技能 | 调研设计（问卷、访谈、焦点小组、car clinic）、统计分析、数据整合、预测建模、BI/AI 工具、跨部门沟通、英文报告 |
| 常见产出 | 月度/季度市场报告、细分与价格带地图、销量预测、政策影响简报、进入/加码建议的事实底座 |
| 常见指标 | 预测偏差、报告时效、洞察被采纳数、细分覆盖完整度、数据源覆盖 |

JD 来源见文末；以上为多份招聘描述的共性归纳，不是单一企业标准。

## 二、先写口径

固定国家/地区、期间、新车/二手车、车辆类别（轿车/SUV/MPV/皮卡按目的国定义）、动力、统计阶段（零售/注册/批发/进口）、品牌层次、币种与汇率日期、数据截止日与检索日。分子分母同口径；零售、注册、批发、海关分表。

## 三、市场与宏观分析流程

完整单国画像按 [country-market-workflow.md](references/country-market-workflow.md) 执行；本节只列市场与宏观部分。

1. **规模与结构**：总量、同比、R12M、YTD；车身、动力、价格带结构；区分实际值/机构估算/预测。
2. **需求驱动**：人口与城镇化、收入与就业、消费者信心、利率与车贷可得性、汇率、通胀、能源价格、保有量与报废率。
3. **政策与法规**：关税、购置税/增值税、补贴与以旧换新、排放/安全/数据法规、进口配额与认证；只引用官方现行文件，否则标"未核验"。
4. **供给与竞争**：在售品牌/车型数、集中度、进口/本地组装比例、产能与交付周期；竞争细节交给销售价格板块。
5. **预测与情景**：基线/乐观/悲观三情景，写明假设；不把 GDP 增速直接换算成汽车增速，不把政策利率当车贷 APR。
6. **判断**：市场处于扩张/见顶/收缩？增长来自渗透率、置换、政策还是一次性需求？哪些细分可进入？

## 四、指标

| 指标 | 定义 | 限制 |
|---|---|---|
| 市场规模 | 同口径年销量/注册量 | 不混零售与批发 |
| 渗透率 | 每千人销量/保有量 | 分母人口口径一致 |
| 细分结构 | 细分销量占比与增速 | 细分定义跨期一致 |
| 集中度 | CR3/HHI | 无完整品牌分布不报精确值 |
| 进口依存 | 进口量 ÷ 市场规模 | 进口 ≠ 零售 |
| 政策敏感度 | 受关税/补贴/税费影响的销量占比 | 需官方税率与适用条件 |
| 预测偏差 | 实际 − 预测，按期间滚动 | 记录预测版本与假设 |

## 五、中资品牌结构与对比（必做）

先定口径，三口径分开列、不混算：**中资资本**（含中方控股的当地组装）、**中国品牌**（自主品牌）、**中国原产**（海关原产地）。同一张表只允许一种口径。

| 必做项 | 算法 | 用途 |
|---|---|---|
| 中资份额占比 | 中资品牌销量 ÷ 同口径市场总量；金额口径单列 | 判断中资整体位置 |
| 中资品牌数与集中度 | 在售中资品牌数、中资内部 CR3 | 判断是"集群进入"还是"单点突破" |
| 中资增速贡献 | Δq 拆解中中资部分：大盘/细分/份额三项各占多少 | 区分真份额夺取与大盘红利 |
| 中资细分与价格带分布 | 中资销量按车身/动力/价格带拆 | 判断是否挤在同一细分 |
| 中国原产进口结构 | 进口量、进口额、单位价值、来源国 | 贸易事实，不当零售份额 |
| 中资政策暴露 | 受关税/补贴/认证/原产地规则影响的销量占比 | 判断政策风险敞口 |

对比列固定为：中资、日系、韩系、欧系、美系、本土品牌；每行给量、份额、同比、ASP 或价格带中位数。

判断规则：
- 中资份额上升但 ASP 下降，多为价格换份额，需与 `auto-export-method-sales-price` 的折扣率交叉验证。
- 中资品牌数增加而中资总份额不变，说明内部互食，不是市场突破。
- 中国原产进口增长不等于中国品牌零售增长；平行出口与转出口要先剔除。
- 结构性诊断（为何卡住、拐点信号）交给 `auto-export-method-china-brand`。

## 七、输出

```
# [国家] 市场与宏观简报（[期间]）
## 0 口径与数据边界
## 1 规模与结构
## 2 需求驱动（收入/就业/利率/汇率/能源/保有量）
## 3 政策与法规（含核验状态）
## 4 供给与竞争概览
## 5 预测与三情景（含假设）
## 6 中资品牌结构（份额/品牌数与集中度/增速贡献/价格带/原产进口/政策暴露）
## 7 判断：扩张/见顶/收缩；机会与风险
## 8 数据缺口
```

## 八、边界

- 不编造销量、渗透率、预测值；缺则 NA。
- 不把部分月份年化、不把累计同比当单月同比。
- 不把中国原产当中国品牌，不把进口量当零售。
- 政策/税率/认证只认官方现行文件，否则标"未核验"。
- 宏观相关不等于因果；预测必须写假设与版本。
- 中资对比必须标口径；不许把三个口径的数字拼成一个"中国车份额"。
