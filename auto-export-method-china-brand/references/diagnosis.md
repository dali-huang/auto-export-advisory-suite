# 中资品牌诊断细则

配套 `auto-export-method-china-brand`。核查日：2026-10-30。本文件只给指标定义、证据要求和判断规则，不含具体市场结论。

## 一、口径判定

### 判定顺序

1. 先问用途：看资本控制、看品牌形象、还是看贸易与原产地？三者可以同时要，但必须分表。
2. 再查归属：品牌注册地、集团控股结构、生产地与最后组装地、出口申报原产国。
3. 最后建集合：中资资本集合、中国品牌集合、中国原产集合，分别列品牌清单与生效日期。
4. 品牌/集团股权与产地会变，按分析期间的历史归属计算，不用今天的归属倒填历史。

### 常见边界案例

| 案例 | 中资资本 | 中国品牌 | 中国原产 | 处理 |
|---|---|---|---|---|
| MG（上汽） | 是 | 是 | 视产地 | 三列分建；当地组装部分不等于中国原产 |
| Volvo / Polestar（吉利控股） | 是 | 否 | 视产地 | 只进"中资资本"列，不并入中国品牌份额 |
| 中国产特斯拉 | 否 | 否 | 是 | 只进"中国原产"列，用于贸易/关税分析 |
| 中国产外资品牌车型 | 视股权 | 否 | 是 | 同上；不因产地改品牌归属 |
| 合资企业生产的中国品牌 | 视股权 | 是 | 否 | 品牌列计入，原产列不计 |
| 平行进口的中国品牌车 | 是 | 是 | 是 | 销量若进入当地统计则计入，但需标注非授权渠道 |

无法确认归属时写"待核验"，不默认归入任一口径。

## 二、五维指标与证据

### 产品

| 指标 | 定义 | 最低证据 |
|---|---|---|
| 细分覆盖 | 品牌在售车型覆盖的细分数 ÷ 市场主要细分数 | 官方配置表、在售车型清单 |
| 价格-配置匹配 | 同价位段内，本品配置相对直接竞品的增减项 | 配置表逐项对比，标年款 |
| 动力覆盖 | 燃油/混动/插混/纯电在售组合 | 官方规格 |
| 安全与可靠性 | 当地或国际安全评级、召回、投诉 | 评级机构、监管召回库、保修数据 |
| 当地适应性 | 油品、路况、气候、充电、维修便利 | 本地测试/媒体测评、售后反馈 |

误判：配置表项数多不等于客户价值高；中国版配置不能当当地版；未在当地验证的可靠性不能引用中国口碑。

### 价格

| 指标 | 定义 | 最低证据 |
|---|---|---|
| 价格带位置 | 本品 TP 中位数在细分价格阶梯中的排名 | 同配置 TP 或 Quote |
| 折扣率 | 1−TP/MSRP | 成交或报价证据，注明条件 |
| 金融渗透 | 金融方案成交占比 | 授权内部数据；公开无则 NA |
| 残值 | 3 年/5 年保值率 | 当地残值机构、拍卖/二手车平台，标样本 |
| TCO | 购置＋能源＋保险＋保养＋融资−残值 | 同持有期/里程假设 |

误判：拿 MSRP 当 TP；拿入门款 MSRP 对比竞品高配 TP；把厂商贴息当经销商让利；用一个国家的残值套另一个国家。

### 渠道

| 指标 | 定义 | 最低证据 |
|---|---|---|
| 在营网点 | 按类型分列，含状态与观察日 | 官方 locator＋协会/地图交叉 |
| 城市覆盖 | 覆盖城市 ÷ 目标城市集合 | 同上；目标城市先定义 |
| 单店效率 | 品牌零售量 ÷ 加权网点数 | 上牌/零售数据＋网点表 |
| 库存与库龄 | 在库/在途、>90/180 天占比 | 授权 DMS/内部报表 |
| 经销商盈利 | 单店毛利、返利依赖、现金流 | 授权财务数据；无则 NA |
| 退网 | 期间关闭/转品牌网点数 | 门店状态变化、新闻 |

误判：门店总数多＝渠道强；把二级网点与 4S 混算；用发运量算单店效率；把"签约未开业"计入在营。

### 品牌

| 指标 | 定义 | 最低证据 |
|---|---|---|
| 认知/考虑/信任 | 分阶段漏斗比例 | 当地调研（授权）、方法透明的公开调查 |
| 声量/SOV | 提及量 ÷ 品类总提及 | 监测方法、媒体集合、期间透明 |
| 口碑/NPS | 推荐意愿、投诉主题 | 授权调研、公开评论抽样 |
| 品牌溢价 | 同配置相对竞品的价格接受度 | 成交价差、调研；不能只用 MSRP |

误判：社媒声量＝品牌力；中国平台声量＝当地声量；一次负面事件＝长期品牌损伤；KOL 好评＝消费者信任。

### 运营

| 指标 | 定义 | 最低证据 |
|---|---|---|
| 交付周期 | 下单到交付天数 | 订单/物流数据 |
| 订单履约 | 按期交付率、取消率 | 授权内部数据 |
| 备件满足率 | 首次满足订单 ÷ 备件订单 | 售后系统 |
| 一次修复率 | 首次进店修复完成比例 | 售后系统 |
| 质量与召回 | 召回数、故障率、三包成本 | 监管库、保修数据 |
| 总部响应 | 决策/审批周期、支持到位率 | 内部流程记录 |

误判：用全球平均代替当地；用保修政策文本代替履约能力；用一次暗访代表全网服务。

## 三、中资八问的证据包

| 问题 | 需要取证 | 缺证据时 |
|---|---|---|
| 品牌信任 | 当地媒体叙事、社媒情绪、调研、历史质量事件 | 标"未取得"，只做定性线索 |
| 残值 | 残值机构/拍卖/二手车平台成交，按车型年款 | 给区间或 NA，不套用他国残值 |
| 售后备件 | 网点覆盖、备件等待、保修履约、投诉 | 缺则列为风险，不假设达标 |
| 渠道经济 | 单店销量/毛利/库存/返利/退网 | 仅内部授权可得；缺则 NA |
| 原产地合规 | 关税、原产地规则、认证、补贴资格官方文件 | 标"未核验"，不据此定价/投资 |
| 平行出口 | 灰色进口量、价差、保修覆盖、品牌管控 | 用海关/上牌/保修线索，标推断 |
| 集团内竞争 | 同集团品牌价格带重叠、渠道共用、内部价差 | 用公开价格与网点数据推断，标推断 |
| 总部权责/地缘 | 授权清单、决策周期、数据/制裁/舆情事件 | 只列已知事件，不推测内部授权 |

## 四、增长质量拆解示例

以下为**假设值，仅演示算法**，不是任何真实市场数据。

| 细分 | M₀ | M₁ | s₀ | s₁ | 增长效应 | 份额效应 | 交互 |
|---|---|---|---|---|---|---|---|
| A | 1,000 | 1,100 | 5.0% | 6.0% | +5.0 | +10.0 | +1.0 |
| B | 500 | 450 | 2.0% | 2.5% | −1.0 | +2.5 | −0.25 |

- 细分 A 贡献 `100×0.05 + 1000×0.01 + 100×0.01 = 16.0`
- 细分 B 贡献 `−50×0.02 + 500×0.005 + (−50)×0.005 = 1.25`
- 合计 `Δq = 17.25`；若 q₀=60，则 q₁=77.25。

解读：增量主要来自 A 细分内份额提升（10.0），其次大盘增长（5.0）；B 细分在萎缩但份额提升抵消了大部分下滑。此时不能简单说"品牌增长 28.75%"，要说明增长质量。

## 五、生命周期判断

先看连续 4–6 期的趋势，再看相对同业的位置，不用单期数据定阶段：

- **进入期→爬坡期**：上牌量连续上升、网点从首批扩展到多城、复购/推荐出现、售后投诉可控。
- **爬坡期→规模期**：份额稳定、单店销量不靠新开店拉动、折扣率稳定、渠道盈利为正。
- **规模期→守成期**：份额见顶、折扣上升、增长依赖促销、库龄上升。
- **进入退坡期**：连续份额下滑、退网增加、库存高、备件与保修投诉上升。

同一品牌不同车型可处于不同阶段；按车型判断再汇总品牌。

## 六、反模式

1. 把"中国品牌整体"当一个同质主体，忽略集团与品牌差异。
2. 用中国市场表现推断海外表现，忽略法规、路况、税费、客群与竞品结构。
3. 用进口量、发运量或批发量代替当地零售/上牌。
4. 用促销期份额证明品牌力，用单月/单城数据外推全国。
5. 用 MSRP 折扣率替代真实 TP 折扣，忽略金融、置换和税费。
6. 用门店总数证明渠道能力，忽略单店效率与经销商盈利。
7. 用社媒声量证明品牌力，忽略认知、考虑、信任与成交。
8. 把关税/认证/补贴按传闻写进结论，未取得官方现行文件。
9. 把"中资控股"与"中国品牌"混用，导致份额、残值和政策判断全错。
10. 数据缺口用行业均值填充，制造精确假象。
