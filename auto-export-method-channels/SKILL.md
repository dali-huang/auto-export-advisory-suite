## 现代应用：权责与数字零售（[现代实务改编]）

**权责表**：对每种模式逐项填列——进口商、货权、库存融资、价格决定权、客户合同、客户数据、交付、售后、保修、召回协作、税务责任、退出成本、争议机制。

- 填写实际合同约定与执行证据；未约定标"缺口"，不能按模式名称自动推定。
- 真实代理的认定与价格安排须根据当地现行法律和实际风险承担结构核验。
- BMW 案例（S4）仅说明一种历史实施方案，不把全国统一价推广为所有国家的合法要求。

**CRM 闭环**：

```
去重线索 → 有效触达 → 预约 → 试驾 → 订单 → 实际交付 → 首保
```

- 每一步保留：事件时间、来源、负责渠道、车型、失单原因，定义观察窗口。
- 订单取消需回写；预约量、订单量与交付量分别呈现，不能叠加为销量。
- 获客与成交分工变化时先明确归属、佣金、数据访问与服务交接，再推广系统。
- 经销商激励可测试零售质量、及时回款、服务和数据质量等指标的组合。
- 激励指标须防：重复记账、虚假交付、过度压库、牺牲消费者体验；权重需试点验证。

## 决策规则（来源标注）

1. 当准备选渠道模式时 → 先分清进口主体、消费者合同主体和服务承担方，再比较模式。（第6、18章，Rosenbloom 第8版主题定位；[汽车实务改编]，未核验原书同义规则）
2. 当新增线上触点时 → 先解决线索、订单、交付与售后的协调和冲突，再推广系统。（第4、15章，Rosenbloom 第8版主题定位；S3 摘要支持协调问题，S4 提供整合案例；CRM 字段、去重方式和归属安排均为[现代实务改编]）
3. 当伙伴销售弱时 → 先检查能力、服务任务和收益结构，再设计激励；不把提高返利当成唯一处方。（第7、9章，Rosenbloom 第8版主题定位；[汽车实务改编]）
4. 当评价伙伴时 → 只看批发采购不足以说明终端经营质量，须加入零售、回款、库龄与服务验证。（第14章，Rosenbloom 第8版主题定位；[汽车实务改编]，原书具体绩效指标、权重和阈值未核验）
5. 当评估市场变量对渠道长度的影响时 → 与市场距离越远、市场越大、密度越低，越倾向用中介；低单位价值→较长渠道；笨重、易腐、定制、技术性强产品与新产品→短渠道。（第6章，Rosenbloom 第8版；S5 讲义支持；原书措辞未核验）
6. 当设计伙伴激励时 → 先了解成员需求与问题（成员调研/渠道审计），再用合作安排、伙伴联盟、分销规划三类支持；强制型权力更易激化冲突。（第4、9章，Rosenbloom 第8版；S5 讲义支持；细节单源，标未核验）
7. 当出现渠道冲突时 → 执行侦测、评估影响、化解三任务；冲突≠竞争，强制型权力更易激化。（第4章，Rosenbloom 第8版；S5 第4章与 S7 第4章摘要交叉）
8. 当分析目标市场时 → 从地理、规模、密度、购买行为（何时/何地/如何/谁买）四维度切入。（第8章，Rosenbloom 第8版；S7 第8章与 S6 目录交叉）

## 反模式（改编警示，非书中明确警告）

1. 以"直营/代理更先进"代替权责与双方经济性比较 — 模式名称不等于实际权责，须按合同与现金责任判断。[汽车实务改编]
2. 用厂家批发完成率奖励伙伴，却忽略库存、终端交付和现金风险 — 只看采购量会诱发压库与虚假交付。（第14章，Rosenbloom 第8版主题定位；[汽车实务改编]）
3. 上线 CRM 但没有线索归属与服务交接 — 会放大多渠道冲突而非解决。（第4、15章，Rosenbloom 第8版主题定位；[现代实务改编]）
4. 把一个品牌的一次公告当成全行业最优模式与最新落实情况 — 单案例不能外推为行业标准。[汽车实务改编]
