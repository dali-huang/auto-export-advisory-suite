# 海外产品规划细则

配套 `auto-export-method-product`。本文件给步骤、证据和判断规则，不预填具体市场数据。

## 0. 固定口径

- 国家/区域、期间、细分定义（车身+动力+价格带）、客群、年款、在售/停售/预售、MSRP 或 TP 口径。
- 细分定义跨期一致；年款与配置表保留版本号和抓取日。
- 竞品池按直接替代优先（用途/客群/车身/可成交价格），不用"所有中国品牌"当竞品池。

## 1. 需求与场景

| 项 | 取证 | 输出 |
|---|---|---|
| 细分规模与增长 | 注册/零售数据、协会数据 | 各细分 TAM、增速、价格带分布 |
| 客群与购买因素 | 调研、访谈、车主口碑、销售反馈 | 首要购买因素排序（价格/空间/油耗/品牌/售后/残值） |
| 用车场景 | 城市/高速/家庭/商用/气候/路况/停车 | 场景-配置需求映射 |
| 政策与准入 | 官方法规、认证、补贴、税费 | 必须满足项与成本影响 |
| 未来需求 | 人口/收入/能源/基础设施趋势 | 3–5 年细分方向与假设 |

调研方法可用问卷、深访、焦点小组、car clinic、试驾；小样本只作方向，不报总体比例。

## 2. 竞品产品力

建配置矩阵（行=车型/年款/价格，列=车身、动力、尺寸、安全、座舱、ADAS、舒适、能耗、质保、售后）：

1. 同价位对齐：用 TP/MSRP 同口径，不用入门价对比高配。
2. 装备价值：逐项估值，形成"装备价值/价格"；估值方法透明。
3. 实测与口碑：安全评级、媒体测评、车主投诉、召回。
4. 静态体验：空间、坐姿、视野、储物、材质、车机；有条件做 teardown。
5. 差距结论：按"客户感知强/弱"与"成本高/低"分四象限，优先补高感知低成本项。

## 3. 型谱与配置

- 画细分 × 价格带矩阵：每个格子标在售车型、销量、份额、TP 区间。
- 找空白带：无车型或只有高价低配；同时验证该带是否有真实需求。
- 找重叠：相邻车型价格重叠、同门内耗、渠道互相压价。
- Trim walk：从入门到顶配的价格阶梯是否连续，标配/选装是否造成"乞丐版"或"顶配才有"。
- SKU 复杂度：动力/配置/颜色组合数与制造、库存、认证成本；不是越多越好。
- 配置上下车：高频配置标配化、低频配置选装化；用选装率与成交数据验证。

## 3.5 中资产品组合对标

把中资品牌当作一个组合来看，同时保留单品牌差异：

| 项 | 做法 | 输出 |
|---|---|---|
| 型谱覆盖差 | 中资有/无的细分×价格带 vs 日系、欧系、韩系、本土品牌 | 缺口清单（双向） |
| 价格带占位 | 中资 TP 分位（P25/P50/P75）与竞品分布叠加 | 集中度与空白带 |
| 配置价值比 | 同价位中资装备价值 ÷ 非中资装备价值；装备估值方法公开 | 比值与敏感性 |
| 内部重叠 | 中资品牌间价格带/细分重叠车型数、同门内耗 | 重叠矩阵 |
| 本地化缺口 | 法规/油品/气候/路况/充电/语言/ADAS 数据合规未适配项 | 上市风险清单 |
| 组合节奏 | 中资新车上市计划密度 vs 竞品改款节奏 | 冲突与窗口 |

判断：中资型谱过度集中 = 价格战风险；配置价值比过高 = 成本与残值压力；内部重叠高 = 渠道互食。诊断交给 `auto-export-method-china-brand`。

## 4. 本地化适配清单

| 类别 | 检查项 |
|---|---|
| 法规认证 | 整车型式认证、排放、安全、灯光、噪声、数据/隐私、ADAS 法规 |
| 能源与基础设施 | 油品标号、乙醇/柴油质量、充电标准与功率、家庭充电条件 |
| 环境 | 高温/高湿/高海拔/沙尘/盐雾、空调与冷却、防腐 |
| 路况 | 路况质量、坡道、拥堵、长途高速、载重 |
| 消费习惯 | 语言/地图/语音、手机互联、后排使用、颜色/材质偏好 |
| 使用与售后 | 保养周期、备件可得、维修技能、道路救援 |
| 成本 | 关税、认证、运输、本地化率、配置增删的成本影响 |

每一项写"必须改/建议改/无需改"与证据；法规项未取得官方文件标"未核验"。

## 5. 产品经济性

- 商业论证：销量假设、价格、净收入、变动成本、渠道支持、认证/物流一次性投入。
- 单车贡献：`净收入 − 变动成本 − 渠道支持`；授权财务数据，缺则 NA。
- 选装/衍生：选装率、附件、金融/保险捆绑，按当地接受度。
- 复杂度成本：SKU、动力、颜色、认证组合对制造与库存的影响。
- 盈亏平衡：固定投入/单车贡献；标假设与敏感性。

## 6. 生命周期

| 阶段 | 关键动作 | 证据/门槛 |
|---|---|---|
| 预研 | 细分机会、产品定位、目标成本 | 市场数据、竞品、商业论证 |
| 立项/Gate | 规格、价格带、销量目标、投资 | Charter/产品包需求、财务模型 |
| 开发 | 配置冻结、法规认证、本地化验证 | 配置表版本、认证计划 |
| 上市前 | 培训、卖点、渠道准备、售后备件 | 上市 readiness 清单 |
| 在售 | 年款、配置调整、促销支持 | 销量、成交价、选装率、投诉 |
| 改款/退市 | 竞争力刷新、残值管理、库存清理 | 份额、折扣、库龄、残值 |

## 7. 输出模板

```
# [市场] 产品诊断
## 0 口径与版本
## 1 细分与需求
   细分规模/增速｜价格带｜购买因素｜场景
## 2 竞品产品力矩阵
   车型｜年款｜价格｜尺寸｜动力｜安全｜座舱｜ADAS｜能耗｜质保｜来源
## 3 型谱地图
   细分×价格带｜在售车型｜销量｜份额｜空白/重叠
## 4 配置建议
   标配/选装｜目标车型｜理由｜成本/价值｜验证指标
## 5 本地化适配
   必须改/建议改/无需改｜证据｜成本｜责任
## 6 经济性
   销量假设｜净收入｜单车贡献｜盈亏平衡｜敏感性
## 7 生命周期与节奏
## 8 缺口与下一步取证
```

## 8. 证据分层

| 等级 | 证据 |
|---|---|
| A 官方 | 配置表、价格表、法规认证、召回公告 |
| B 可核验第三方 | 安全评级、媒体实测、注册/零售数据、车主投诉 |
| C 授权内部 | 成本、选装率、成交价、售后工单、产品规划文件 |
| D 线索 | 销售口述、论坛、KOL、经销商物料 |

A/B 可支撑结论；C 仅授权后使用；D 只作方向，不单独支撑投资决策。

## 9. 检查

- [ ] 细分、价格带、年款、在售状态口径已固定
- [ ] 竞品池是直接替代，不是"中国品牌集合"
- [ ] 价格用 TP/MSRP 同口径，未用入门价对比高配
- [ ] 中国版配置未直接当当地版；法规项已核验或标"未核验"
- [ ] 型谱地图同时看空白、重叠、内耗与需求真实性
- [ ] 经济性缺授权数据时标 NA，未编造成本/选装率
- [ ] 建议带验证指标（销量、选装率、成交价、退订率）
