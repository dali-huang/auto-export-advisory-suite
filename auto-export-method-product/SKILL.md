# 产品规划与产品力分析（Product）

本方法为 [乘用车实务改编]，对应"产品规划 / 整车产品经理（海外）/ 商品企划"岗位。它回答"该市场需要什么产品、现有型谱缺什么、配置怎么定、中资产品组合差在哪、什么时候上/改/退"，不替代研发、法规认证和财务的最终决策。

## 一、岗位画像（JD 归纳）

| 项 | 内容 |
|---|---|
| 典型职责 | 区域市场与用户场景研究；竞品品牌/车型/配置功能研究；产品机会分析与改款提案；产品竞争力与属性定义（属性一层解读、二层指标细化）；配置阶梯、亮点配置与版型（trim）设置；动力选型对标（燃油/混动/纯电）；车型定位与竞品对位、上市价格建议；VTC（车辆技术配置）管理；首批车 MIX（颜色/动力占比）；新品海外导入与上市节奏、成本、质量管控；上市后 N+3/N+6 调研；3–5 年产品规划与销量预测、全生命周期管理 |
| 常见技能 | 市场与竞品分析、用户研究、型谱/trim walk、配置与价值分析、商业论证与销量预测、项目管理与跨部门协同（研发/制造/销售/法规）、法规与认证基础、英语/小语种沟通 |
| 常见产出 | 产品规划书、型谱路线图、Charter/产品包需求、配置表与 VTC、首批车 MIX 建议、上市 Gate 材料、N+3/N+6 调研报告、年款/改款/退市建议 |
| 常见指标 | 细分覆盖、配置命中率/选装率、上市节点达成、产品线销量目标达成、单车贡献、首批车 MIX 准确度、型谱复杂度 |

JD 来源见文末；以上为多份招聘描述的共性归纳，不是单一企业标准。海外产品岗普遍要求"英语可作为工作语言、能接受海外出差"，部分岗位约 1/3 时间在海外。

## 二、JD 拆出的工作内容（一年怎么跑）

| 阶段 | 典型动作 | 交付物 |
|---|---|---|
| 1 规划期（年度/3–5 年） | 竞品品牌与车型研究、配置功能拆解、动力选型对标、产品机会与改款提案、分车型销量预测 | 产品规划书、型谱路线图 |
| 2 定义期 | 竞争力与属性定义（一层解读→二层指标细化）、配置阶梯与亮点配置、版型设置、定位与竞品对位、上市价格建议 | Charter/产品包需求、配置表、VTC |
| 3 导入期 | 法规认证与本地化适配、首批车 MIX（颜色/动力占比）、成本与质量管控、上市信息核查 | 上市 Gate 材料、首批订单建议 |
| 4 上市后 | N+3/N+6 调研、配置与价格微调、传播信息落地跟踪 | 复盘报告、改进清单 |
| 5 生命周期 | 年款、中改、特别版、退市与残值影响 | 生命周期计划 |

## 三、核心分析框架

完整步骤见 [product-workflow.md](references/product-workflow.md)，主线是六件事：

1. **需求与场景**：目标细分、客群、购买因素、用车场景（城市/高速/家庭/商用/气候/路况）。
2. **竞品产品力**：同细分同价格带的配置矩阵、装备价值、安全/质量/口碑、实测表现。
3. **型谱覆盖**：细分 × 价格带矩阵，找空白、重叠、内耗与缺口；检查 trim walk 是否连续。
4. **本地化适配**：法规认证、油品、气候、路况、充电、语言/地图、ADAS/数据合规、配置增删。
5. **产品经济性**：成本、价格、单车贡献、选装/衍生、复杂度与制造效率。
6. **生命周期**：上市 Gate、年款、改款、退市与残值影响。

## 四、关键判断

| 问题 | 看什么 | 常见误判 |
|---|---|---|
| 型谱是否完整 | 细分×价格带覆盖、相邻车型价格重叠、空白带 | 车型多＝覆盖好 |
| 配置是否有竞争力 | 同价位装备价值、标配/选装、感知价值 | 配置项多＝客户价值高 |
| 是否本地适配 | 法规、油品、气候、路况、充电、语言/地图 | 中国版配置直接当当地版 |
| 产品是否赚钱 | 单车贡献、选装率、复杂度、制造成本 | 只看 MSRP 不看净收入 |
| 节奏是否正确 | 上市窗口、竞品动作、生命周期位置 | 用全球节奏套当地市场 |
| 中资组合是否有结构问题 | 中资品牌间的价格带重叠、配置同质化、内部互食 | 中资总量增长＝每个中资品牌都健康 |

## 五、指标

| 指标 | 定义 | 限制 |
|---|---|---|
| 细分覆盖率 | 在售车型覆盖的主要细分数 ÷ 市场主要细分数 | 细分定义先固定 |
| 价格带覆盖 | 各价格带是否有在售车型 | 用 TP/MSRP，标口径 |
| 配置命中率 | 热门配置在在售 SKU 中的可得比例 | 需当地配置表与销量结构 |
| 选装率 | 选装件装配数 ÷ 对应车型销量 | 授权内部数据 |
| 装备价值比 | 同价位竞品装备价值 ÷ 本品装备价值 | 装备估值方法要透明 |
| 单车贡献 | 净收入 − 变动成本 − 渠道支持 | 授权财务数据 |
| 上市节点达成 | 实际 SOP/上市日 vs 计划 | 记录版本与变更 |
| 首批车 MIX 准确度 | 实际颜色/动力占比 vs 计划 | 需首批订单与实销数据 |
| 型谱复杂度 | SKU 数、动力组合、配置组合 | 复杂度有成本，不是越多越好 |
| 中资型谱份额 | 中资品牌车型数 ÷ 同细分在售车型数 | 与销量份额分开报 |

## 六、中资品牌产品对标（必做）

先定口径（中资资本 / 中国品牌 / 中国原产），三口径不可混算；把中资品牌作为一个**组合**对比，而不是只比某一家。

| 必做项 | 算法 | 用途 |
|---|---|---|
| 中资型谱覆盖差 | 中资有、竞品无的细分/价格带；竞品有、中资无的空白 | 找中资组合的结构缺口 |
| 中资价格带占位 | 中资车型 TP/MSRP 分布 vs 日系/欧系/韩系/本地品牌 | 判断中资是否挤在同一价格带 |
| 中资配置价值比 | 同价位中资装备价值 ÷ 非中资装备价值 | 判断"以配置换价格"的强度与可持续性 |
| 中资内部重叠度 | 中资品牌之间价格带/细分重叠车型数 | 识别内部互食与同质化 |
| 中资本地化缺口 | 法规、油品、气候、路况、充电、语言、ADAS 数据合规未适配项 | 上市前风险清单 |

判断规则：
- 中资总量增长不等于单个中资品牌健康；先看份额在品牌间如何分配。
- 中资型谱集中在 1–2 个价格带时，价格战风险高、溢价空间小。
- 配置堆叠可以短期换份额，但要看装备成本、残值、保险与保修成本是否同步恶化。
- 中国版配置不能直接当目标国配置；法规项一律标"未核验"直到取得官方文件。
- 结构性诊断（为何卡住、拐点在哪）交给 `auto-export-method-china-brand`，本板块只提供产品侧事实。

## 七、输出

```
# [市场] 产品诊断（[期间]）
## 0 口径：细分/价格带/客群/年款/在售状态
## 1 需求与场景
## 2 竞品产品力矩阵
## 3 型谱地图（细分×价格带）与缺口
## 4 中资品牌产品对标（覆盖差/价格带占位/配置价值比/内部重叠/本地化缺口）
## 5 本地化适配清单（法规/油品/气候/路况/充电/语言/ADAS）
## 6 产品经济性（成本/价格/贡献/选装）
## 7 生命周期与节奏
## 8 建议：补什么车、改什么配置、退什么车；验证指标
## 9 数据缺口
```

## 八、边界

- 不编造成本、销量、选装率；缺则 NA。
- 不用中国版配置、价格、法规直接推断目标国。
- 法规认证以官方现行文件为准，否则标"未核验"。
- 配置多不等于产品力强；车型多不等于型谱健康。
- 不把中资品牌合并成一个"中国车"结论；品牌间差异要单独列。
- 产品建议必须给出验证指标（销量、选装率、成交价、退订率），不输出伪精确评分。
