## 核心框架：单次价格决策卡（P）

适用：上市定价、渠道促销、竞品降价应对、汇率变化。以第1章利润与价格销量权衡为依据；操作细节均为汽车实务改编。

1. **明确交易层**：分别记录厂家出口价、进口商批发价、经销商成交价和消费者含税总支付；填写进口主体、币种、Incoterms版本/地点、付款与货权条件。消费者TCO不能直接当厂家应收收入。
2. **识别真实替代**：记录竞品可成交价格、配置、交付期、融资、保修与使用条件；比较私人、车队和网约等客群。停用宣传指导价代替成交价的比较。
3. **建经济性桥**：列净收入、物流、税费承担、保修预计成本、优惠及金融支持；标固定/变动与已发生/新增成本。用同一交易主体、币种、期间比较方案。
4. **测需求门槛**：先求保持贡献所需销量，再列基准、上行、下行与竞品跟价情景；给证据不足项，不伪造弹性。成本增加、现金缺口或服务负担同步测算。
5. **批准有限试点**：给适用客群/车型、优惠期限、责任人、复盘日期、终端交付与贡献目标；未证明价格有效时不承诺全国长期执行。

产出表：`交易层｜客群｜净价/币种｜单车贡献｜需求门槛｜现金影响｜竞品反应｜证据｜批准/试点/暂缓`。

## 五条原著/作者规则与对应汽车指令

1. 如果销量目标与利润冲突，先评估长期利润；份额本身不是定价目的。**A，第1章 pp.6–7**。汽车指令（P）：同时比较出口发运、终端交付和贡献，避免以向渠道压货证明促销有效。
2. 如果单位分摊成本随销量变化，不把成本加成当唯一售价依据。**A，第1章 pp.4–5**。汽车指令（P）：上市前计算市场可实现净价能承担的投入；本地化单独做投资与销量爬坡分析。
3. 如果缺可靠弹性，先问价格变化需多少销量变化才能维持贡献。**A，第1章 pp.7–9**。汽车指令（P）：输出门槛及证据区间，不把门槛说成销量预测。
4. 如果客户价值不同，研究价值驱动差异后分群。**B，Nagle访谈；主题对应第2章，T**。汽车指令（P）：按用途、里程、充电及融资条件比较TCO；不能把客户口头低报价直接当价值上限。
5. 如果采购压价，不奖励纯粹更强硬的讨价；研究价值与顾虑，用一致政策处理。**B，Nagle访谈；主题对应第5章，T**。汽车指令（P）：优惠应有可核查交换条件和审批记录，例如回款、服务或成交期限；不得借此固定独立经销商转售价。

## 章节级补充规则（第7版章号；A目录为基，交叉验证后收录）

1. 理性价格区间介于参考价值与总经济价值之间；总经济价值＝次优替代品价格＋正负差异化价值之和，货币价值与心理价值分别估算，走捷径代价高。（第7版第2章节名"竞争参考价/货币/心理价值/捷径的高代价"A；第7章第1步"定可行价格区间"A；Pricing Companion与旧版书评内容交叉）
2. 价值模型按"对客户损益表/资产负债表的影响"量化，不按产品特性加总：同一特性对不同客户的价值不同。（B，Nagle本人2024观点，Ibbaka转述并与S3播客交叉；对应第7版第2章）
3. 案例：寿命3倍的O型圈卖出5倍价——价值驱动含停机避免与产能收益，停机敏感客群支付意愿远高于计划停机客群；应按价值交付方式与数量细分。（B，Nagle播客案例，Ibbaka转述；正文未核验，主题对应第7版第2章）
4. 细分定价靠"度量＋围栏"落地：四类围栏＝买家识别/购买地点/购买时间/购买数量；动态与收益管理是时点围栏的特例。（第7版第4章节名，A）
5. 应对竞品降价先过五问：回应成本是否低于可避免销售损失；对手能否再降价；多轮反应总成本是否可承受；其他市场连带风险；风险市场规模是否值得。（第7版第6章节名，A；"多数价格战源于信号失误而非必然"由Pricing Companion与旧版书评交叉）
6. 定价水平五步：定可行价格区间→选撇脂/渗透/中性→算盈亏平衡销量变化→测弹性→计心理因素并沟通新价。（第7版第7章节名，A；T&F官方章节页摘要交叉D）
7. 价值级联＝创造价值→沟通价值→定价结构→定价政策→定价水平，并管理竞争环境；第6版引入、第7版精炼，各环节价值-价格缺口是诊断起点。（D：Ibbaka解读与官方简介"refined value cascade"、Pricing Companion三方交叉；总纲对应第7版第1章）
8. 汽车出口注意：第10章"汇率调整四种通用策略"（p.248）与"灰市/平行进口"（p.251）仅目录A核验、正文规则未取得，不得当作已验证原书规则引用。[实务改编]套件中的汇率情景与平行进口对策仍为P。

## 当代工具：三项汽车实务改编（P）

### 贡献及折扣瀑布

每车净收入＝同口径基础价－即时折扣－预计返利－厂家承担的金融贴息－其他销售支持。
单车贡献＝净收入－该方案的单车增量/可避免成本。先核实折扣是否已包含在基础净价、金融支持是否已计入成本，防止重复扣除。
账面毛利、贡献、现金收款分别展示；预计返利注明计算条件，未核验汇率和税负标假设。
第11章价格带（p.284）与价格瀑布（p.285）已由预览详细目录A核验；本模板仍非该章正文提炼。

### 价格变化的代数校验

同一主体、同一期间、固定成本不变且贡献为正时：`基准贡献=(P0−V0)×Q0`；`方案门槛 Q1=基准贡献/(P1−V1)`。
P为不重复扣优惠的净收入，V为可变/增量成本，Q为相应销量；这是独立代数推导P（第7版第9章盈亏平衡公式推导见附录9B p.236，目录A核验，正文未比对）。
若新方案固定投入改变，则分子增加相应固定成本变化；若新贡献≤0，不使用该除法。
现金时点、库存减值、蚕食其他车型和未来返利另列，公式不能覆盖全部经营效果。

### TCO、金融与本地化情景

按相同持有期/里程比较购置、能源、保险、保养、融资及残值；单独列首付、月供、尾款，不把低月供说成低总成本。
融资需真实APR/费用/期限/尾款报价；残值和维修数据不足时给范围。保修对价值的影响须以实际条款和履约能力验证。
CBU/SKD/CKD比较固定投入、爬坡、当地成本与资金占用；关税优势不自动证明当地制造划算。
现代层依据套件[S4]的本地化和服务经济性模块；上述计算为P，不是BYD或奇瑞公开的定价方法。

## 检查清单（P）

- [ ] 竞品价格可成交，配置/税费/融资/交付条件可比；客群与交易主体明确。
- [ ] 优惠、返利和支持只有一次入账；净收入、贡献与现金区分。
- [ ] 需求门槛不冒充预测；销量、汇率、竞品反应有情景。
- [ ] 总拥有成本与月供分开，残值及成本缺口已标注。
- [ ] 税、汇、补贴、竞争法按决策当次和具体国家核验；授权与试点复盘可追溯。

## 反模式与边界

- 原著警告：仅靠成本加成、客户压价、份额目标决定价格。**A，第1章 pp.4–7**。
- 实务风险（P）：用出货量代替零售；将所有折扣视为无成本；低月供掩盖尾款；用一国残值套全球。
- 这是有限预览及作者访谈支持的小规模提炼，非全书逐章验证；第2–12章详细规则待持有合法正文后补充。
- 第12章目录不构成各国法律意见；价格差异、代理和转售限制须按合同及当地法律审查。
- AI不能凭历史汇总销量可靠推断因果弹性；小样本、新品牌、缺供与政策变化时尤其需试点。
- 国家、动力、经营模式及内部成本未知，因此不提供统一售价、折扣底线或利润率。
