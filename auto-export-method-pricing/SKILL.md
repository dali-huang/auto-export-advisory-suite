```

  define 适用客群/车型、优惠期限、责任人、复盘日期、终端交付与贡献目标

    do not 承诺全国长期执行
```

### 框架 2：贡献及折扣瀑布 [实务改编]

适用场景：设计折扣、返利、金融贴息、销售支持时，核实真实净收入与单车贡献。
依据：第11章价格带与价格瀑布（目录已核验，正文未取得）；计算为实务改编。

公式：
- 每车净收入 ＝ 同口径基础价 − 即时折扣 − 预计返利 − 厂家承担的金融贴息 − 其他销售支持
- 单车贡献 ＝ 净收入 − 该方案的单车增量/可避免成本

瀑布表：

| 层级 | 金额/币种 | 计算条件 | 是否已入账 |
|------|-----------|----------|------------|
| 基础价 | | 同口径（含税/不含税、FOB/CIF） | — |
| − 即时折扣 | | 按车型/客群/期间 | 是 / 否 |
| − 预计返利 | | 达成率、季度/年度 | 是 / 否 |
| − 金融贴息 | | 厂家承担部分 | 是 / 否 |
| − 其他销售支持 | | 物流补贴/展台/培训 | 是 / 否 |
| ＝ 净收入 | | | |
| − 单车增量成本 | | 可变/可避免 | |

校验：折扣是否已包含在基础净价、金融支持是否已计入成本——防止重复扣除。账面毛利、贡献、现金收款分别展示；预计返利注明计算条件，未核验汇率和税负标假设。

### 框架 3：价格变化的代数校验 [实务改编]

适用场景：判断降价/提价需多少销量变化才能维持贡献。
依据：第9章盈亏平衡公式推导（附录9B 目录已核验，正文未比对）；本公式为独立代数推导。

同一主体、同一期间、固定成本不变且贡献为正时：
- 基准贡献 ＝ (P0 − V0) × Q0
- 方案门槛 Q1 ＝ 基准贡献 ÷ (P1 − V1)

P ＝ 不重复扣优惠的净收入；V ＝ 可变/增量成本；Q ＝ 相应销量。
若新方案固定投入改变，分子增加相应固定成本变化；若新贡献 ≤ 0，不使用该除法。
现金时点、库存减值、蚕食其他车型、未来返利另列，公式不能覆盖全部经营效果。

## 决策规则（来源标注）

五条原著/作者规则（汽车应用为 [实务改编]）：

1. 当销量目标与利润冲突时，先评估长期利润；份额本身不是定价目的。（第7版第1章）
   - [实务改编] 同时比较出口发运、终端交付和贡献，避免以向渠道压货证明促销有效。
2. 当单位分摊成本随销量变化时，不把成本加成当唯一售价依据。（第7版第1章）
   - [实务改编] 上市前计算市场可实现净价能承担的投入；本地化单独做投资与销量爬坡分析。
3. 当缺可靠弹性时，先问价格变化需多少销量变化才能维持贡献。（第7版第1章）
   - [实务改编] 输出门槛及证据区间，不把门槛说成销量预测。
4. 当客户价值不同时，研究价值驱动差异后分群。（第7版第2章；作者访谈）
   - [实务改编] 按用途、里程、充电及融资条件比较 TCO；不能把客户口头低报价直接当价值上限。
5. 当采购压价时，不奖励纯粹更强硬的讨价；研究价值与顾虑，用一致政策处理。（第7版第5章；作者访谈）
   - [实务改编] 优惠应有可核查交换条件和审批记录（回款/服务/成交期限）；不得借此固定独立经销商转售价。

## 条件指令（when / then）

1. when 用户问"这车定多少钱 / 折扣给多少"，then 先跑【单次价格决策卡】步骤 1–2，缺交易层或竞品成交价时一次性列问。
2. when 用户提供了基础价与各项扣减，then 用【贡献及折扣瀑布】表核算净收入与单车贡献，标注重复扣除风险。
3. when 用户问"降 X 元要多卖多少才划算"，then 用【代数校验】算 Q1 门槛，并声明该值非销量预测。
4. when 用户问"值不值这个价 / 客户嫌贵"，then 用【TCO 情景】对比次优替代品，区分货币价值与心理价值。
5. when 用户问"竞品降价了怎么办"，then 先过【应对五问】，不直接建议跟价。
6. when 用户提供的是宣传指导价而非成交价，then 要求替换为可成交价格再比较。
7. when 用户把低月供当低总成本，then 拆解首付/月供/尾款/APR，指出尾款与融资成本。
8. when 数据不足（弹性/残值/汇率），then 给出情景区间与假设，不伪造点估计。
9. when 新方案贡献 ≤ 0，then 停止使用代数除法，直接标记方案不可行。
10. when 决策涉及多国或本地化，then 单独列 CBU/SKD/CKD 固定投入与爬坡，不因关税优势直接下结论。
