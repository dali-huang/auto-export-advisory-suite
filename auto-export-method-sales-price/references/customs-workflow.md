# 海关贸易与进口市场分析

本方法为数据机构统计规范基础上的 [乘用车实务改编]，不是某本书的原文。具体来源及取数记录见 [customs.md](customs.md)，执行分析前读取。

## 工作流

1. 固定目的国、期间、流向、产品范围、新旧车、数量/金额单位和 HS 版本。先查目的国海关进口，再查中国海关出口交叉验证；官方入口不可取数时尝试 UN Comtrade，不能把空白填成零。
2. 从 8703 及目的国相关细分子目核查乘用车范围，按具体 HS 版本、动力和车型定义排除不属于目标范围的车辆。不能把全部 8703 都称作轿车或直接等同当地乘用车市场；CKD/SKD 依申报分类核验，不能默认一套零件等于一辆车。
3. 下载原始文件，保留筛选条件、元数据、下载日、表页/行标识及修订状态。有数量估算、保密、缺报或单位不是辆/台时单独标记；不由重量换算辆数。
4. 同一报告国、月份、互斥商品叶子节点去重汇总。不叠加 HS 总项与子项，不叠加 World 与各伙伴国；区分原产国、发运国与最终目的地。
5. 分析规模、结构、来源依赖及量价变化，再用目的国零售/注册数据判断终端需求。没有品牌字段，不能推算品牌份额；中国原产不等于中国品牌。

## 可复算指标 [汽车实务改编]

| 指标 | 公式与前提 | 可以说明什么 |
|---|---|---|
| 同比 | 本期/上年同月−1；基期为零则 NA | 同范围贸易变化；不拿累计同比当单月同比 |
| 来源国数量份额 | 从该来源进口辆数/全部来源进口辆数 | 进口市场结构，不是全市场零售份额 |
| 来源国金额份额 | 从该来源进口金额/全部来源进口金额 | 金额结构；必须另标，不能混称数量份额 |
| 贸易单位价值 UV | 同一商品范围贸易金额/有效辆数 | 车型组合、估值、运保费等综合变化，不是 TP |
| 动力结构 | 对应动力互斥子目数量/可比总量 | 分母、分类版本一致时才可比较 |
| 镜像差异率 | (目的国报进口−中国报出口)/中国报出口 | 诊断线索；分母为零则 NA，不能直接认定漏报 |

进口常按 CIF、出口常按 FOB，但存在国家例外；以数据集元数据为准。镜像差异先解释运输跨月、转口、伙伴定义、汇率、估值与修订，不强制两边相等。海关均价下跌不能单独证明竞品降价。

## 输出与判定

输出 `期间｜报告国｜伙伴口径｜HS版本/代码｜流向｜辆数/单位｜金额/币种/估值｜估算标记｜来源记录`，附趋势、机会/风险与缺口。

- 可核验：原始值可定位、单位明确且计算可复算。
- 仅能指示：统计覆盖/估算或镜像差异未解决，限制结论。
- 不可得：无权限、验证码、付费或未公布；记录原因及替代源，不承诺已取得逐票数据。

不能仅凭进口增长建议增加发运；将零售、库存和回款交给运营方法论检验。
