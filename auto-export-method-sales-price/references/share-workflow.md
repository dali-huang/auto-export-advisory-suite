# 竞品、份额与增长拆解

本方法为 [乘用车实务改编]，属于"销售与价格"板块。海关进口见 [customs-workflow.md](customs-workflow.md)，价格证据见 [prices-workflow.md](prices-workflow.md)；本文件只处理"谁卖了多少、份额怎么变、增长从哪来"。

## 一、先建竞品池

| 类型 | 定义 | 用途 |
|---|---|---|
| 直接替代 | 用途/客群、车身、动力及可成交价格接近 | 份额与价格对比的主池 |
| 跨级替代 | 价格或车身跨一级，但客群重叠 | 价格战与降级消费分析 |
| 潜在进入者 | 已发布/已签约但未上量 | 前瞻竞争与渠道卡位 |

不能只按排量或 MSRP 选竞品；价格须用 TP 或标"未取得"。竞品池一旦确定，分子分母和跨期比较都用同一池。

## 二、份额口径

| 层次 | 分子 | 分母 | 用途 |
|---|---|---|---|
| 集团 | 集团下品牌销量合计 | 同口径市场总量 | 看资本/集团竞争 |
| 品牌 | 单一品牌销量 | 同口径市场总量 | 看品牌位置 |
| 车型 | 车型销量 | 同细分总量 | 看单品贡献 |

- 集团、品牌、车型三层分别建表，不可相加后又称"市场份额"。
- 维护品牌别名、集团归属及生效日期，防止双计（如集团下多品牌、合资品牌）。
- 分母必须与分子同口径：零售对零售、注册对注册、批发对批发；覆盖不足时先披露，不先算份额。

## 三、指标与公式

| 指标 | 定义 | 限制 |
|---|---|---|
| 份额 | 品牌/车型销量 ÷ 同口径总量 | 分子分母覆盖一致 |
| 份额变动 | 本期份额 − 基期份额，用百分点 | 不用百分比变化混淆 |
| CR3 | 前三品牌份额之和 | 描述集中度，不套法律阈值 |
| HHI | Σ(百分数份额²) | 无完整品牌分布不报精确全市场值 |
| 增长拆解 | `Δq = s₀×(M₁−M₀) + M₁×(s₁−s₀)` | 市场效应＋份额效应 |
| 细分拆解 | 见下式 | 市场/结构/份额内三因子 |
| 细分机会 | 销量、增长、份额、TP、供货、售后覆盖并列 | 低竞争也可能是低需求 |
| 竞品证据矩阵 | 年款配置、现金价、融资、交期、质保、网点、在售状态及来源 | 配置多 ≠ 客户价值 |

细分层三因子（品牌 b、细分 i）：

```
Δq_b = Σᵢ (Mᵢ₁−Mᵢ₀)·s_bi₀         ← 细分市场增长
     + Σᵢ Mᵢ₀·(s_bi₁−s_bi₀)        ← 细分内份额变化
     + Σᵢ (Mᵢ₁−Mᵢ₀)·(s_bi₁−s_bi₀)  ← 交互项
```

滚动 12 月、同比和 YTD 同期并列；不得把部分月份年化成全年。份额变化须检查样本增减、缺供、新车上市、车队大单、政策和促销，不把相关性写成因果。

## 3.5 中资品牌份额专项

中资不能作为一个混算标签，必须按三种口径分表，并在表头写清用的是哪一种：

| 口径 | 定义 | 常见误用 |
|---|---|---|
| 中资资本 | 中方持股/控股，含当地 CKD 组装 | 与"中国品牌"混算 |
| 中国品牌 | 自主品牌（BYD、Chery、MG、Geely、Great Wall、Changan 等） | 把合资品牌算进来 |
| 中国原产 | 海关原产地为中国 | 当作零售份额 |

输出字段（每组必填）：

- 中资集团合计：量、份额、同比、份额变动 pp、ASP 或 TP 中位数。
- 中资内部拆解：品牌数、CR3、HHI（只在中资池内算）、品牌间份额变动。
- 中资来源结构：中国原产进口量/额/单位价值，与总进口对比。
- 中资价格位置：TP 分位（P25/P50/P75）与同价格带非中资车型对比。
- 中资增长拆解：市场效应、细分效应、份额效应、交互项各占多少。
- 平行进口单列：识别后从零售份额中剔除或单列，不混入中资官方渠道份额。

判断规则：

- 中资份额上升但份额增量主要来自新进入品牌，是"池子变大"而非"头部变强"。
- 中资份额上升同时 ASP 下降，先做 `1−TP/MSRP` 与净收入核算，再评价增长质量。
- 中资内部 CR3 下降 + 品牌数上升 = 内卷期，价格战风险高。

## 四、归因检查

销量变化先排除口径变化，再按顺序归因：大盘 → 细分结构 → 细分内份额 → 一次性因素（车队、铺货、降价清库、上市首年）。批发增长而零售不增长时，先查渠道库存，不当作真实需求。

## 五、输出

`品牌/车型｜统计阶段｜本期量｜同期量｜分母｜份额｜变动pp｜来源/行号｜覆盖限制`

另附：集中度、增长拆解表、细分机会矩阵、竞品证据矩阵、数据缺口。数据不足时不报全市场排名或虚构精确份额。

## 六、检查

- 总量是否含未报送品牌？分子分母是否同口径？
- 是否把中国原产当中国品牌、把进口量当销量、把批发当零售？
- 是否把集团与品牌相加、把别名重复计入？
- 结论是否限定在样本范围，是否区分相关与因果？
