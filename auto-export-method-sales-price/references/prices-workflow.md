# TP / MSRP 与价格证据

TP 默认指消费者车辆成交价（transaction price）；如果业务中指 transfer price，改用集团关联交易/出口层口径，不能混算。定价策略使用套件原定价方法，本模块负责取证和比较。执行前读 [prices.md](prices.md)。

## 证据分层

| 标签 | 最小证据 | 允许表述 |
|---|---|---|
| TP-实证 | 已成交合同/发票与成交状态，退款取消剔除；脱敏且授权可用 | 对应样本的已实现价格，不称全国均价 |
| ATP-统计 | 发布机构、样本/加权方法、车型地区期间、优惠税费定义 | 机构统计均价；有模型估计应明确 |
| Quote | 可定位经销商、日期、车型配置、库存及优惠条件的有效报价 | 报价/可成交报价，仍不称已成交 TP |
| MSRP | 该国车厂官方配置表/价格表、有效期、脚注 | 厂商建议价，不等于消费者总支付 |
| Scenario | 明列假设 | 情景结果，不能放进真实成交样本 |

## 工作流 [汽车实务改编]

1. 固定国家/地区、年款、配置、动力、选装、新旧车、币种、现金/金融、私人/车队。MSRP 与 TP 一一匹配；“起售价”不能比较高配 TP。
2. 从当地厂商官方价表取得 MSRP；经销商网站报价与有效期限另列。历史分析用当时的版本，不能用今天价格倒填历史。
3. 获得授权成交记录或方法透明的 ATP；保存来源、日期、税费和优惠定义。样本量、城市、渠道及覆盖未知就披露未知；不虚构隐私记录或付费库访问。
4. 分开记录裸车价、强制运送/交付费、选装、税费/注册、金融成本、置换及政府补贴。标准化后比较；同一优惠只入账一次。置换高估不得全算新车折扣。
5. 对现金和金融分别计算。首付+各期还款+尾款+强制费用−可确认补贴，给出名义总支付；现值比较另注明贴现率。不能用月供代替 TP；不叠加互斥现金优惠与低息方案。

## 指标

- 同口径折扣率 = `1−TP/MSRP`；价格实现率 = `TP/MSRP`。分母为零/缺失则 NA；允许 TP 高于 MSRP，先查加价及口径。
- 同质成交样本报告 n、期间、覆盖、中位数/P25/P75及加权方式；极端值标记并解释，不能静默删除。
- 多配置总体实现率用 `Σ成交价/Σ对应MSRP`，不能将平均 TP 除以入门款 MSRP；若只有机构均值，不能反推具体配置折扣。
- 无 TP 时明确“未取得”，可输出 MSRP/Quote 表及取证需求，不能按固定折扣估成真实 TP。

输出：`国家城市｜日期/有效期｜车型年款配置｜证据标签｜MSRP｜TP/报价｜币种税费｜优惠/金融条件｜样本n/覆盖｜来源定位｜可比性`。仅将可比价格交给定价方法做贡献与折扣瀑布。
