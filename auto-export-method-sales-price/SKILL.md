# 销售与价格分析（Price · 销售数据）

本方法为 [乘用车实务改编]，对应"定价分析 / 销售运营 / 市场数据"岗位。它回答"进口多少、谁在卖、份额多少、真实成交价多少、增长从哪来"，不替代产品规划、渠道和售后分析。

## 一、岗位画像（JD 归纳）

| 项 | 内容 |
|---|---|
| 典型职责 | 维护竞品产品/价格/销量数据库；trim walk 与装备调整后的价格定位；成交价与竞品价差；折扣、渠道毛利、商务支持与净收入情景；月度付款/金融方案建模；份额与销量预测；定价建议包与决策 Gate |
| 常见技能 | Excel/SQL/BI、价格与财务建模、竞品情报、细分与价值链分析、情景分析、数据质量管理、跨部门沟通 |
| 常见产出 | 价格定位分析、TP/MSRP 对比、折扣与净收入模型、份额表、增长拆解、定价建议包 |
| 常见指标 | 价格实现率、折扣率、份额、预测偏差、数据库时效、竞品价差 |

JD 来源见文末。

## 二、三条取证线

| 线 | 回答 | 入口 |
|---|---|---|
| 海关贸易 | 进口多少、从哪来、单位价值 | [customs-workflow.md](references/customs-workflow.md) |
| 竞品份额 | 谁卖多少、集中度、增长来源 | [share-workflow.md](references/share-workflow.md) |
| TP/MSRP | 指导价与真实成交价、折扣与价格带 | [prices-workflow.md](references/prices-workflow.md) |

三条线同期间、同口径；海关均价不是 TP，进口份额不是零售份额。

## 三、流程

1. **口径**：国家、期间、零售/注册/批发/进口、车辆范围、币种与汇率、品牌层次。
2. **贸易**：HS 版本、流向、数量/金额单位；中国海关与目的国海关交叉验证。
3. **份额**：集团/品牌/车型三层；集中度 CR3/HHI；增长拆解 `Δq=s₀×(M₁−M₀)+M₁×(s₁−s₀)`；细分层用三因子。
4. **价格**：MSRP 官方价表；TP 分层（实证/ATP/Quote/Scenario）；折扣率 `1−TP/MSRP`、实现率 `TP/MSRP`；价格阶梯与空档。
5. **情景**：折扣、渠道毛利、商务支持对净收入的影响；金融方案月供；汇率与税费敏感性。
6. **判断**：份额变化来自大盘、细分、份额夺取还是一次性因素；价格是否有空间；竞品价格动作是否可持续。
7. **输出**：份额表、价格表、增长拆解、定价建议与验证指标。

## 四、指标

| 指标 | 定义 | 限制 |
|---|---|---|
| 进口量/额 | 海关统计口径 | 不等于终端销量 |
| 单位价值 | 金额 ÷ 数量 | 含运费/税则差异，非 TP |
| 份额 | 品牌/车型销量 ÷ 同口径总量 | 分子分母覆盖一致 |
| 集中度 | CR3/HHI | 无完整分布不报精确值 |
| 价格实现率 | TP ÷ MSRP | 同配置同税费 |
| 折扣率 | 1 − TP/MSRP | 区分厂商支持与经销商让利 |
| 净收入/单车 | 净收入 ÷ 销量 | 授权财务数据 |
| 预测偏差 | 实际 − 预测 | 记录版本与假设 |

## 五、中资品牌专项（必做）

单列一组中资指标，不与"进口"或"亚洲品牌"混算。口径三选：中资资本 / 中国品牌 / 中国原产；每个数字标注取了哪一种。

| 必做项 | 算法 | 限制 |
|---|---|---|
| 中资份额占比 | 中资集团合计 ÷ 同口径总量；再拆品牌、车型 | 分子分母覆盖一致 |
| 中资内部集中度 | 中资 CR3/HHI | 只在中资池内计算，不与全市场 CR3 混用 |
| 中国原产进口份额 | 中国原产进口量 ÷ 总进口量；金额口径单列 | 贸易口径，不当零售份额 |
| 中资单位进口价值 | 中国原产进口额 ÷ 数量 | 含运费税则差异，非 TP |
| 中资价格实现率 | 中资品牌 TP ÷ MSRP（同配置同税费） | 无 TP 标"未取得" |
| 中资折扣率 | 1 − TP/MSRP，区分厂商支持与经销商让利 | 不与其他品牌默认折扣对比 |
| 中资价格带分布 | 中资车型 TP 分位（P25/P50/P75）vs 竞品 | 用成交价，不用入门 MSRP |
| 中资增长拆解 | 市场效应 + 细分效应 + 份额效应 + 交互项 | 需两期同口径细分数据 |

判断规则：
- 中资份额上升 + 价格实现率下降 = 价格驱动型增长，先算净收入再谈"份额胜利"。
- 中资内部 CR3 上升而品牌数不变，多为头部集中；品牌数增加而 CR3 下降，多为新进入者摊薄。
- 中国原产进口高增长但零售份额不动，先查平行出口、转出口与库存积压。
- 中资品牌平行进口会污染零售份额与 TP，须先识别并单列。
- 结构性诊断交给 `auto-export-method-china-brand`。

## 六、输出

```
# [市场] 销售与价格分析（[期间]）
## 0 口径与数据边界
## 1 海关贸易（量/额/来源国/单位价值）
## 2 份额与集中度（集团/品牌/车型）
## 3 增长拆解（市场/细分/份额/一次性）
## 4 中资品牌专项（份额/内部集中度/原产进口/价格实现率/价格带分布/增长拆解/平行进口）
## 5 TP/MSRP 与价格阶梯（含证据标签）
## 6 折扣、净收入与金融情景
## 7 判断与建议（价格/产品组合/验证指标）
## 8 数据缺口
```

## 七、边界

- 海关均价不当 TP；进口份额不当零售份额。
- 中国原产不当中国品牌；集团与品牌不相加。
- 折扣要区分厂商支持、经销商让利、金融贴息与置换。
- 预测与情景写假设，不把单月/单城外推全国。
- 无授权的净收入、渠道毛利、成交明细标 NA。
- 中资份额必须写明口径，且不与"亚洲品牌""进口车"合并报数。
