# 售后能力分析（After-sales）

本方法为 [汽车售后实务改编]，对应"售后经理 / 服务经理"岗位。它回答"服务网络够不够、备件等多久、保修能不能兑现、客户满不满意、售后赚不赚钱"，不把保修文本或网点数直接当能力。

## 一、岗位画像（JD 归纳）

| 项 | 内容 |
|---|---|
| 典型职责 | 服务/备件/钣喷车间运营；进厂台次、工时、配件、精品、延保、保险续保等经营指标；备件库存与周转；保修与索赔；CSI/NPS 与客诉；厂家标准与政策落地；团队与培训；预算、成本与毛利 |
| 常见技能 | 售后运营、备件管理、保修/索赔、客户关系、财务与库存、数据分析、团队管理、厂家与供应商协调 |
| 常见产出 | 售后经营计划、服务网络规划、备件清单与库存策略、保修履约报告、CSI/投诉复盘、售后 readiness 清单 |
| 常见指标 | 进厂台次、产值/毛利、备件周转与满足率、工时效率、一次修复率、CSI/NPS、投诉响应、保修成本 |

JD 来源见文末。

## 二、流程

1. **口径**：国家、品牌、车型、保有量、期间、授权数据范围。
2. **服务网络**：服务站/钣喷/救援按类型统计，计算城市覆盖与服务半径；与销售网络分开。
3. **备件**：常用件清单、价格、等待天数、满足率、库存周转；区分常用件与冷门件。
4. **保修**：年限/里程、覆盖件、免责、可转让；找拒赔/履约投诉；估算保修成本。
5. **维修质量**：一次修复率、返修率、技师认证、专用工具、技术通报执行。
6. **客户**：CSI/NPS、投诉率/响应时长、回店率、客户关怀。
7. **质量与召回**：召回批次、响应时长、故障率、保修成本。
8. **经济性**：售后产值/毛利、单店售后盈利、客户生命周期价值（授权）。
9. **判断**：售后能否支撑当前销量与保修承诺；上市前门槛是否达标。

详细指标与证据分层见 [aftersales-workflow.md](references/aftersales-workflow.md)。

## 三、指标

| 指标 | 定义 | 限制 |
|---|---|---|
| 服务网点数/覆盖率 | 在营服务站按类型分列 | 与销售网点分开 |
| 服务半径 | 服务人口 ÷ 服务站；或最近距离 | 人口口径一致 |
| 备件满足率 | 首次满足订单 ÷ 备件订单 | 授权 DMS |
| 备件等待 | 下单到到货中位数/P90 | 区分常用/冷门件 |
| 保修覆盖 | 年限/里程/覆盖件/免责/可转让 | 官方手册 |
| 一次修复率 | 首次修复完成 ÷ 进店工单 | 授权售后系统 |
| CSI/NPS | 厂商/第三方调研 | 标样本/城市/期间 |
| 投诉响应 | 首次响应小时数 | 监管/平台口径 |
| 召回响应 | 通知到实施天数 | 监管召回库 |
| 售后产值/毛利 | 单店月均产值、毛利率 | 授权内部 |

## 四、判断规则

- 保修条款 ≠ 履约能力；服务 locator ≠ 服务可用；网点多 ≠ 服务好。
- 售后弱会先影响残值、保险、复购与口碑，再影响销量。
- 新市场上市前：备件首批清单、服务半径、保修履约、救援覆盖是门槛。
- 经销商售后长期亏损、靠销售返利补贴，是渠道不健康的信号。
- 召回响应慢、备件等待长是品牌信任的领先风险指标。

## 五、中资品牌售后对比（必做）

中资品牌的售后约束通常集中在**备件跨境供应、服务网络扩张速度、保修履约能力**三点；对比时把"政策文本"和"实际履约"分开。

| 必做项 | 算法 | 限制 |
|---|---|---|
| 中资服务网点数与覆盖 | 在营服务站按类型分列，算城市覆盖与服务半径 | 与销售网点分开 |
| 中资服务半径 | 服务人口 ÷ 中资服务站；或最近距离 | 人口口径一致 |
| 中资备件等待 | 下单到到货中位数/P90，区分常用件/冷门件 | 授权 DMS；无则用公开等候反馈并标样本 |
| 中资备件满足率 | 首次满足订单 ÷ 备件订单 | 授权数据，缺则 NA |
| 中资保修覆盖与履约 | 年限/里程/覆盖件/免责/可转让 + 拒赔案例 | 文本与履约分开报 |
| 中资一次修复率 | 首次修复完成 ÷ 进店工单 | 授权售后系统 |
| 中资 CSI/NPS | 厂商或第三方调研 | 标样本/城市/期间 |
| 中资召回响应 | 通知到实施天数 | 监管召回库 |
| 中资残值/保险可得性 | 二手残值率、保险承保意愿 | 公开拍卖/保险数据，缺则 NA |

对比列固定为：中资、日系、韩系、欧系、本土品牌；给服务网点数、备件等待、保修年限、CSI、残值率。

判断规则：
- 中资网点扩张快于备件与技师能力建设，是售后口碑风险的领先信号。
- 保修文本写得长但拒赔案例多，等于履约能力弱；两者必须分开报。
- 中资冷门件等待显著长于日欧系，会先影响保险与残值，再影响复购。
- 售后亏损靠销售返利补贴的经销商，退网风险高。
- 残值、保险与品牌信任的结构性归因交给 `auto-export-method-china-brand`。

## 六、输出

```
# [市场] 售后能力分析（[期间]）
## 0 口径与数据授权
## 1 服务网络（类型/城市/半径）
## 2 备件（清单/价格/等待/满足率）
## 3 保修（条款/履约/成本）
## 4 维修质量（一次修复/返修/认证）
## 5 CSI/投诉/回店
## 6 召回与质量
## 7 售后经济性
## 8 中资品牌售后对比（服务网点/半径/备件等待/保修履约/一次修复/CSI/召回/残值）
## 9 判断：能否支撑销量/残值/复购；上市门槛
## 10 数据缺口
```

## 七、边界

- 不编造 CSI、备件满足率、售后毛利；缺则 NA。
- 不把保修文本当履约，不把投诉平台样本外推全网。
- 服务网点与销售网点同址只算一个物理场地，但能力分开评估。
- 法规/召回以官方数据为准；访问受限要记录原因。
- 中资对比不得用"保修年限"替代履约能力，也不得用单条投诉外推整体。
