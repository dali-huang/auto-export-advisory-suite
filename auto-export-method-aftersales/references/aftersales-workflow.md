# 售后能力分析

本方法为 [乘用车实务改编]，不属于 4P 本身，但会通过残值、保险、复购和口碑反噬销量。售后数据多为内部授权数据，取不到就标"未取得"，不编造 CSI、备件满足率或经销商售后毛利。

## 一、分析范围

| 模块 | 内容 |
|---|---|
| 服务网络 | 服务站、钣喷中心、道路救援、服务半径 |
| 备件供应 | 备件仓、常用件清单、价格、等待天数、满足率 |
| 保修与三包 | 年限/里程、覆盖件、可转让性、免责条款、履约投诉 |
| 维修质量 | 一次修复率、返修率、技师认证、专用工具 |
| 客户满意 | CSI、NPS、投诉率、响应时长、回店率 |
| 质量与召回 | 召回数量、响应时长、故障率、保修成本 |
| 售后经济 | 售后产值、单店售后毛利、客户生命周期价值（授权内部） |

## 二、证据分层

| 等级 | 最小证据 | 允许表述 |
|---|---|---|
| A 官方条款 | 厂商保修手册、服务政策、备件价目表、官方 locator | 政策与服务网络"写了什么" |
| B 可核验运营 | 召回公告、监管投诉库、保险/维修协会数据、公开服务记录 | 有第三方留痕的服务表现 |
| C 授权内部 | DMS 工单、备件满足率、CSI、售后毛利 | 该品牌"实际做到什么" |
| D 用户线索 | 论坛、社媒、投诉平台、车主群 | 仅作线索，不单独作为事实 |

保修文本不等于履约能力；官方 locator 不等于服务可用；投诉平台样本有偏差，不能直接外推全网。

## 三、指标

| 指标 | 定义 | 前提 |
|---|---|---|
| 服务网点数/覆盖率 | 在营服务站按类型分列；覆盖城市 ÷ 目标城市 | 与 network-workflow 同口径 |
| 服务半径 | 服务人口 ÷ 服务站数；或平均最近服务距离 | 说明人口口径 |
| 备件满足率 | 首次满足订单 ÷ 备件订单 | 授权 DMS；无则 NA |
| 备件等待天数 | 下单到到货的中位数/P90 | 区分常用件与冷门件 |
| 备件价格指数 | 常用件价格 ÷ 竞品同件价格 | 同车型级别、同原厂/副厂口径 |
| 保修覆盖 | 年限、里程、覆盖件、可转让、免责 | 以官方手册为准 |
| 一次修复率 | 首次进店修复完成 ÷ 进店工单 | 授权售后系统 |
| 返修率 | 30/90 天内返修 ÷ 完工工单 | 同上 |
| CSI / NPS | 厂商或第三方调研得分 | 标样本、城市、期间、方法 |
| 投诉率/响应时长 | 投诉数 ÷ 保有量；首次响应小时数 | 监管/平台口径 |
| 召回数/响应时长 | 召回批次、涉及车辆、通知到实施天数 | 监管召回库 |
| 售后产值/毛利 | 单店月均产值、售后毛利率 | 授权内部；公开无则 NA |

## 四、工作流

1. 固定国家、品牌、车型、期间、保有量口径与数据授权范围。
2. 服务网络：按类型统计在营服务站，计算城市覆盖与服务半径；与销售网络分开计。
3. 备件：获取常用件清单、价格与等待时间；有授权数据才报满足率。
4. 保修：逐条比对年限/里程/覆盖件/免责/可转让；找履约投诉与拒赔案例。
5. 质量与召回：查监管召回库、故障率与保修成本；记录响应时长。
6. 客户满意：CSI/NPS/投诉/回店率；无授权调研则只用公开线索。
7. 竞品对标：选 3–5 个直接替代品牌，同车型级别、同城市、同期间。
8. 判断：售后能否支撑当前销量、保修承诺、残值与复购；输出门槛与缺口。

## 4.5 中资售后专项

在第七步竞品对标中，把中资作为单独一列，并加做以下字段：

| 字段 | 算法 | 限制 |
|---|---|---|
| 中资服务网点覆盖 | 中资在营服务站 ÷ 同一目标城市集合 | 与销售网点分开 |
| 中资备件等待 | 下单到到货中位数/P90，常用件与冷门件分列 | 授权 DMS；否则用公开等候反馈并标样本 |
| 中资备件满足率 | 首次满足订单 ÷ 备件订单 | 无授权标 NA |
| 中资保修履约 | 保修文本 + 拒赔/履约案例 + 预计保修成本 | 文本与履约分开报 |
| 中资一次修复率 | 首次修复完成 ÷ 进店工单 | 授权售后系统 |
| 中资 CSI/NPS | 厂商或第三方调研 | 标样本/城市/期间 |
| 中资召回响应 | 通知到实施天数 | 监管召回库 |
| 中资残值/保险 | 二手残值率、承保意愿 | 缺则 NA |

中资售后的典型约束是跨境备件周期与网络扩张速度快于技师/备件能力。判断时先看"常用件等待 + 服务半径 + 保修履约"，再看网点总数；结构性归因交给 `auto-export-method-china-brand`。

## 五、判断规则

- 售后弱会先体现在残值、保险成本、复购与口碑，再反映到销量；与价格、品牌、渠道交叉验证。
- 新市场上市前，备件首批清单、服务半径、保修履约、道路救援覆盖是门槛；未达标不应以销量目标倒推建店。
- 服务站与销售网点同址时只算一个物理场地，但销售与售后能力分别评估。
- 保修政策越宽不等于成本越低；需看预计保修成本与定价是否覆盖。
- 经销商售后盈利是渠道健康的一部分；长期靠销售返利补贴售后不可持续。
- 召回响应慢、备件等待长是品牌信任的领先风险指标，需单独列入风险清单。

## 六、输出

`品牌｜国家/城市｜模块｜指标｜数值/口径｜期间｜证据等级｜来源｜覆盖/缺口`

另附：服务网络表、备件与保修对比表、CSI/投诉摘要、竞品售后对标、售后风险与门槛清单。

## 七、来源入口

- 厂商保修手册、服务政策、备件价目表、官方服务网点 locator
- 目标国监管召回与投诉数据库
- 保险协会、维修协会、二手车残值机构
- 授权 DMS/售后系统与 CSI 调研（内部）
- 公开投诉平台、车主社区、媒体测评（仅线索）

上述入口按目标国实际可用性核验；访问受限、需登录或需付费时记录原因，不以二手转述替代原始数据。
