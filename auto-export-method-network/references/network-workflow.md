# 经销商网络与门店数量

本方法为 [乘用车实务改编]。数据源入口与字段见文末；执行前先固定"门店"的定义，否则同一国家的两个数字不可比。

## 一、先定网点口径

"门店数量"必须说明计入哪几类，禁止只报一个总数：

| 类型 | 说明 | 计入销售能力 | 常见重复 |
|---|---|---|---|
| 授权经销店 / 4S | 销售+售后一体，签约授权 | 是 | 与同址服务站重复 |
| 城市展厅 / 卫星店 | 只销售或展示，售后外包 | 部分 | 与母店同址 |
| 二级网点 / 加盟点 | 非直接授权，挂靠一级店 | 部分 | 地图 POI 与一级店重复 |
| 服务站 / 钣喷中心 | 只售后 | 否（另计） | 与 4S 同址 |
| 直营店 / 线上线索点 | 厂方直营或仅收线索 | 是/否分开 | 与授权店混算 |
| 快闪 / 临时展点 | 短期 | 否 | 被地图长期收录 |

同一地址、同一投资人、同一物理场地只算一个主店，其他类型另列附属计数。记录 `open_date / close_date / observed_at`，关闭门店不得计入在营数。

## 二、来源优先级与交叉核验

1. **厂商官方门店定位器 / 官网经销商页**：权威，但更新滞后，可能含"已签约未开业"。
2. **当地汽车经销商协会会员名录**：只含会员，缺非会员与二级网点；注明会员覆盖率。
3. **地图 POI（Google Maps、OpenStreetMap、当地地图）**：覆盖全，但含关闭、非授权、同名重复；须抽样电话/官网核验。
4. **经销商集团年报、开业新闻、车展名录**：单点证据，补时间戳。
5. **商业数据库 / 上牌或注册数据中的 dealer 字段**：需授权，注明供应商与覆盖。

至少两个来源交叉；两套数字不一致时分别披露，不取平均、不混算。地图 POI 数高于官方定位器时，先解释差异（二级网点、已关店、非授权），再决定是否计入。

去重键建议 `品牌｜国家｜城市｜地址或坐标（约 100m 网格）｜类型`；连锁集团多店按物理地址拆分，不按投资人合并。

## 二·五 网点核实字段表

核实顺序：存在性 → 规模 → 功能 → 人员 → 状态。每店一行，字段缺失即标"未核实"，不得用同城均值填补。

| 字段 | 取法 | 判定 |
|---|---|---|
| 门店名称 / 地址 / 坐标 | 官网 locator、协会名录、地图 | 坐标落 100m 网格做去重 |
| 授权状态 | 厂商 locator、授权书、门店确认 | 授权 / 二级 / 未授权 / 待核验 |
| 在营状态 | 开业新闻、电话确认、地图评论时间 | 在营 / 已签约未开业 / 关闭 / 转品牌 |
| 类型 | 销服一体、展厅、卫星店、服务站 | 影响是否计入销售能力 |
| 展厅面积 / 维修工位 / 交车区 | 现场、照片、招商资料 | 分旗舰 / 标准 / 卫星 |
| 是否带售后 | 服务 locator、门店确认 | 销售+售后 / 仅销售 / 仅售后 |
| 员工总数与结构 | 现场、招聘信息、门店确认 | 销售/服务/技师/管理层分别记 |
| 认证与培训 | 品牌培训记录、店内公示 | 认证人数 ÷ 编制 |
| VI 与物料 | 现场照片、审核表 | 门头、展厅、标识、展具、数字屏分项 |
| 核验日与来源 | 每次核实都记 | 超过 6 个月视为过期 |

核验完整率 = 已核实字段 ÷ 应核验字段；对外报数时同时报完整率，低于 70% 只作参考。

## 二·六 商圈（消费圈 / 汽车圈）划分

1. **定圈方式**（同城只选一种，跨期不变）：
   - 等时圈：以主要路口/商圈中心为起点，15 与 30 分钟行驶范围（注明交通方式与时段）。
   - 自然聚集带：以"汽车一条街 / 汽车城 / 汽配城"为边界，适合门店高度集中的城市。
   - 网格法：按 3–5 km 网格聚合，适合数据齐全但无明显聚集带的城市。
2. **圈层数据**：圈内上牌量（或零售量）、人口与收入、竞品网点数、本品牌网点数、售后网点数、租金/建店成本。
3. **错配判定**：

| 情形 | 判定 | 动作 |
|---|---|---|
| 销量密度高、网点密度低 | 机会圈 | 优先选址，先做单店商业论证 |
| 销量密度低、网点密度高 | 过度覆盖 | 暂停开店，评估内耗与退网 |
| 销量有、售后无 | 服务缺口 | 补售后或授权现有店 |
| 销量与网点都高、本品牌缺席 | 必争圈 | 找现成投资人，接受更高建店成本 |
| 销量与网点都低 | 观察圈 | 只做低成本曝光，不建店 |

4. **输出**：布局图（圈层底图＋三类点位）＋圈层评分表；每个圈给"进入/加密/维持/退出"四选一结论。

## 二·七 单店战力指数（SPI）与门店管理

**SPI 定义**：`SPI = 月均零售量 ÷ 在营门店数`，按类型（4S/展厅）、城市层级、品牌分层计算；新店满 6 个月才纳入，避免开业爬坡拉低均值。

- 分层看分位：本品牌 P25/P50/P75，对标同城竞品与全国网络。
- 拆解式：`零售量 = 客流 × 留档率 × 试驾率 × 成交率`，`单店毛利 = 零售量 × 单车毛利 + 售后毛利`。
- 诊断对应：客流低→商圈/曝光；留档低→接待与线索响应；试驾低→产品与试驾体验；成交低→价格/金融/谈判；毛利低→折扣与衍生业务。

**门店管理核查**（与 SPI 同步做，避免只考核结果不查能力）：

| 维度 | 检查项 | 达标线（示例，按品牌标准替换） |
|---|---|---|
| 人员配备 | 销售顾问/服务顾问/技师编制、认证率、流失率、培训学时 | 编制 ≥ 品牌最低配置；认证率 ≥ 80% |
| 人员素质 | 产品知识考核、试驾陪同能力、投诉处理 | 季度考核通过率 |
| VI / 视觉 | 门头、展厅动线、标识、展具、物料、数字屏、卫生 | 分项打分，合计 ≥ 85% |
| 流程与系统 | DMS 使用率、线索响应时效、回访完成率、交车流程 | 线索 30 分钟内首响 |
| 合规 | 授权范围、价格公示、售后资质、广告用语 | 无重大违规 |

提升顺序固定：人 → 场 → 流程 → 政策。人员与 VI 未达标时不给返利加码，避免用政策掩盖能力缺口。

## 三、指标与算法

| 指标 | 定义 | 限制 |
|---|---|---|
| 在营网点数 | 按类型分列后求和；默认只计销售类 | 不含关闭、临时点 |
| 城市覆盖数 / 覆盖率 | 有网点的城市数 ÷ 目标城市数 | 目标城市须先定义（如覆盖 80% 上牌量的城市集合） |
| 网络密度 | 网点数 ÷ 每 10 万人口，或 ÷ 每千辆年销量 | 分母口径写明；两种密度不可混比 |
| 单店效率 | 品牌年零售量 ÷ 加权网点数 | 加权按类型折算；不可用发运量 |
| 单店覆盖人口 | 服务人口 ÷ 网点数 | 只描述稀疏度，不代表需求 |
| 覆盖缺口 | 高销量城市 + 低网点密度 | 需同时看该城市竞品网络 |
| 渠道结构 | 授权 / 直营 / 二级占比 | 直营与授权不可直接相加比较效率 |

对比竞品时必须同口径：同一国家、同一期间、同一网点类型集合、同一城市集合。只比"总门店数"会系统性高估含二级网点的品牌。

## 3.5 中资品牌网络专项

中资品牌进入晚、门店多品牌共用，先解决去重，再比数量：

| 字段 | 口径 | 用途 |
|---|---|---|
| 中资网点数 | 只计在营销售类；同一物理地址多品牌只计一次门店，另记挂靠品牌数 | 避免重复计数 |
| 中资品牌挂靠矩阵 | 门店 × 品牌（是否同时经营 ≥2 个中资品牌） | 判断投入摊薄与客户归属 |
| 中资城市覆盖 | 中资有网点城市 ÷ 同一目标城市集合 | 与全市场口径一致 |
| 中资网络密度 | 中资网点 ÷ 每 10 万人口，或 ÷ 每千辆中资年销量 | 两种分母不混用 |
| 中资单店效率 | 中资品牌零售量 ÷ 中资加权网点数 | 不用发运量 |
| 中资建店节奏 | 近 12 个月开业/关闭/转品牌/换投资人 | 净增不等于健康 |
| 中资服务配套 | 有售后能力的网点 ÷ 中资销售网点 | 售后能力另按售后板块评估 |
| 中资商圈集中度 | 中资门店落在机会圈与必争圈的比例 | 识别"只在首都开店"的结构 |
| 中资 SPI | 中资月均零售量 ÷ 中资在营店数 | 与当地主流品牌 P50 对比 |

对比列：中资、日系、韩系、欧系、本土品牌；中资内部再拆头部 3 品牌。判断见 SKILL.md 第五节；结构性归因交给 `auto-export-method-china-brand`。

## 四、判断规则

- 门店多 ≠ 销售能力强：先看单店效率、库存和经销商盈利。
- 门店少 ≠ 市场空白：可能由总代覆盖、售后外包或需求不足造成。
- 高销量城市网点不足，才是可行动的覆盖缺口；低销量城市网点过多，是过度覆盖。
- 新增网点建议前，核对当地建店成本、授权法规、售后资质与候选人资金；渠道设计交给渠道方法论。
- 退网、停业、转品牌是领先指标，须与销量下滑、库龄、返利依赖交叉验证。
- 未核实门店不进合计；核验完整率 < 70% 时，先报"待核验"范围，再给可用范围内的结论。
- 商圈结论必须落到圈：只说"某城门店少"无法指导选址；要说明是哪个圈、错配在哪一侧。
- SPI 只用于同类型、同城市层级比较；混算 4S 与展厅会失真。

## 五、输出

`品牌｜国家/城市｜商圈ID｜网点类型｜网点名称｜地址/坐标｜授权状态｜在营/关闭｜开业日期｜展厅面积｜工位数｜是否售后｜编制/在职｜认证率｜VI 得分｜来源｜核验日｜去重键｜是否计入及理由`

汇总表另附：

- 按类型小计、城市覆盖、密度、单店效率、核验完整率
- 商圈评分表（每圈：销量密度、竞品网点、本品牌网点、售后网点、结论四选一）
- SPI 分布（P25/P50/P75）与拆解（客流/留档/试驾/成交）
- 门店管理得分表（人员配备、VI、流程、合规）
- 与 3–5 个直接竞品的同口径对比、覆盖缺口清单、数据缺口

## 六、来源入口

- 目标国厂商官网的 dealer/find-a-dealer 页面（优先，记录抓取日与页面版本）
- 当地汽车经销商协会会员名录（记录会员数与该品牌会员覆盖）
- OpenStreetMap（可复算、可下载）；Google Maps 等商业地图仅作交叉核验，遵守其条款
- 目标国统计局/交通注册机构的上牌数据（用于单店效率分母）
- 经销商集团年报、开业/退网关店新闻（补时间戳）

地图与协会名录只证明"存在/登记"，不证明"授权在营"；最终计入前以厂商定位器或门店确认回执为准。无法确认的网点标"待核验"，不计入正式合计。
