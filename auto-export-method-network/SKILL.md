# 网络发展分析（Place）

本方法为 [乘用车实务改编]，对应"网络发展 / 渠道发展经理"岗位。它同时回答"网络该铺到哪、找谁、怎么管、健康吗"，以及"现在有多少门店、覆盖如何、单店效率多少"。

## 二、五条工作线

### A. 网络规划与拓展

1. **覆盖目标**：按销量/人口/竞品网络定义目标城市；区分旗舰店、4S、展厅、卫星店、服务站。
2. **缺口测算**：高销量低覆盖城市优先；低销量高覆盖城市暂停扩张。
3. **伙伴筛选**：资金、场地、团队、现有品牌、售后能力、合规记录；做单店商业论证。
4. **签约与开业**：合同条款、建店标准、系统/培训/首批车/备件；开业 readiness 清单。
5. **替换与退网**：绩效不达标、合规问题、资金断裂时的替换路径与客户交接。

### B. 网点核实（先数清，再谈规划）

逐店确认四件事，字段与流程见 [network-workflow.md](references/network-workflow.md)：

1. **存在性**：官网 locator / 协会名录 / 地图 POI 三源交叉，电话或邮件确认；"已签约未开业"单列。
2. **规模**：展厅面积、维修工位数、交车/停车区、员工总数；据此分旗舰/标准/卫星。
3. **功能**：是否带售后（销服一体 / 仅销售 / 仅售后）、钣喷、充电、二手车、金融保险。
4. **人员**：销售顾问、服务顾问、技师、管理层人数与认证；对照品牌最低编制。

核验完整率 = 已核实字段 ÷ 应核验字段。未核实门店标"待核验"，不计入正式合计，不平均填补。

### C. 门店布局与商圈（消费圈 / 汽车圈）

1. **划圈**：按 15/30 分钟行驶等时圈，或以"汽车一条街 / 汽车城"为自然聚集带；同城允许多圈。
2. **叠数据**：把在营网点、竞品网点、上牌量、人口与收入叠到圈层，算圈内网点密度与销量密度。
3. **找错配**：高销量低网点＝机会圈；低销量高网点＝过度覆盖；有销量无售后＝服务缺口。
4. **看自身**：本品牌进了几个圈、位于核心还是边缘、与竞品同圈对撞还是错位。
5. **出结论**：布局图＋圈层评分表（销量、竞品网点、本品牌网点、售后、租金/建店成本）。

### D. 单店战力与门店管理

1. **单店战力指数（SPI）**＝月均零售量 ÷ 门店数，按类型和城市分层；对标同城、全国与竞品分位，衡量经销商固定实力。
2. **战力拆解**：客流 × 留档率 × 试驾率 × 成交率 × 单车毛利，先找短板再定提升动作。
3. **管理核查**：人员配备与素质（编制、认证、流失率、培训学时）、VI/视觉（门头、展厅、标识、物料、数字屏）、流程与系统（DMS、线索响应时效）、合规（授权范围、价格公示、售后资质）。
4. **提升顺序**：先补人（编制/认证）→ 再补场（VI/展车/试驾）→ 再补流程（线索响应/回访）→ 最后才给政策（返利/库存）。

### E. 网络绩效与健康

按 [network-workflow.md](references/network-workflow.md) 执行：

- 在营网点按类型分列，注明授权状态、开业/关闭日期、去重键。
- 城市覆盖、网络密度、单店效率、覆盖缺口，与 3–5 个直接竞品同口径。
- 经销商销量、库存周转、CSI、盈利与返利依赖；缺授权数据标 NA。

## 三、指标

| 指标 | 定义 | 限制 |
|---|---|---|
| 在营网点数 | 按类型分列后求和 | 不含关闭/临时点 |
| 城市覆盖率 | 有网点城市 ÷ 目标城市 | 目标城市先定义 |
| 网络密度 | 网点 ÷ 每 10 万人口或每千辆年销量 | 分母写明 |
| 单店效率 | 品牌零售量 ÷ 加权网点数 | 不用发运量 |
| 单店战力指数 SPI | 月均零售量 ÷ 在营店数，按类型/城市分层取分位 | 分子用零售；新车店满 6 个月才纳入 |
| 网点核验完整率 | 已核实字段 ÷ 应核验字段 | 未核实门店不计入合计 |
| 商圈覆盖率 | 有本品牌门店的机会圈 ÷ 机会圈总数 | 圈层定义先固定，跨期不变 |
| 人员配备达标率 | 达最低编制与认证要求的门店 ÷ 在营门店 | 最低编制按品牌标准 |
| VI 合规率 | VI 检查项通过数 ÷ 检查项 | 现场或照片核查，记录日期 |
| 库存周转 | 销量 ÷ 平均库存 | 授权 DMS |
| 经销商盈利 | 单店毛利/净利、返利占比 | 授权财务 |
| CSI | 销售/售后满意度 | 标样本与方法 |
| 合规达成 | 审计项通过率 | 合同/品牌标准 |

## 四、判断规则

- 门店多 ≠ 渠道强：先看单店效率、库存、经销商盈利。
- 未经核实的门店不进合计：地图 POI 与官网差异先解释（二级网点/已关店/非授权），再决定是否计入。
- 商圈看的是销量密度与网点密度的错配，不是门店绝对数；同圈门店扎堆先看内耗。
- SPI 低但客流高＝转化问题；客流低但商圈好＝选址与曝光问题，两者动作不同。
- 人员与 VI 不达标时，先补基本功再扩网，否则新店只是复制低效。
- 开店速度 ≠ 覆盖质量：新店首年销量、回本周期、售后 readiness 更关键。
- 高销量城市缺网点才是机会；低销量城市多网点是过度覆盖。
- 经销商盈利长期靠返利/压库，是退网领先指标。
- 退网/转品牌要同步客户交接、保修与备件，不能只看数量。

## 五、中资品牌网络对比（必做）

中资品牌多为新进入者，网络口径要先解决"同一门店挂多个品牌"的去重问题，再谈数量。

| 必做项 | 算法 | 限制 |
|---|---|---|
| 中资在营网点数 | 按类型分列后求和，标授权状态 | 不含关闭/临时点 |
| 中资城市覆盖率 | 中资有网点城市 ÷ 目标城市 | 与全市场覆盖率口径一致 |
| 中资网络密度 | 中资网点 ÷ 每 10 万人口或每千辆中资年销量 | 分母写明用哪一种 |
| 中资单店效率 | 中资品牌零售量 ÷ 中资加权网点数 | 不用发运量 |
| 中资多品牌共用率 | 同时经营 ≥2 个中资品牌的门店数 ÷ 中资门店数 | 影响品牌投入与客户归属 |
| 中资建店节奏 | 近 12 个月开业/关闭/转品牌数 | 净增不等于健康 |
| 中资售后配套率 | 有售后能力的网点 ÷ 销售网点 | 售后能力另按售后板块评估 |
| 中资商圈集中度 | 中资门店落在机会圈的比例 | 与全市场同圈分布对比，判断是否只在首都扎堆 |
| 中资 SPI | 中资月均零售量 ÷ 中资在营店数 | 与当地主流品牌分位对比 |

对比列固定为：中资、日系、韩系、欧系、本土品牌；给网点数、覆盖城市数、单店销量。中资内部单列头部 3 个品牌，避免用"中资网络"掩盖品牌差异。

判断规则：
- 中资网点增速快于销量增速 = 单店效率下滑，先看经销商现金流与库存。
- 多品牌共用门店比例高，品牌体验与客户归属弱，厂家投入易被摊薄。
- 中资网络集中在首都/一线城市，二线城市覆盖缺口大，增量空间与售后半径受限。
- 中资经销商盈利若长期靠返利与压库，是退网与口碑风险的领先指标。
- 渠道结构与伙伴治理交给 `auto-export-method-channels`；诊断交给 `auto-export-method-china-brand`。

## 七、边界

- 地图 POI 不是授权在营；协会名录只含会员。
- 门店面积、工位、编制、VI 须现场或照片核验，官网通常不披露；缺失标"未核实"，不填行业均值。
- 商圈划分依赖地图与上牌/人口数据授权；跨城市比较前统一等时圈参数（15/30 分钟、出行方式）。
- 门店总数不可跨类型直接比较；直营与授权分开评估效率。
- 无授权的经销商盈利、库存、CSI 标 NA。
- 建店建议必须含商业论证、建店成本、售后资质与合规检查。
- 中资网点必须去重后统计，多品牌共用门店不能各算一次。
